知识库主页（独立视图）· 三个方向

同一个数据源（`知识库列表/` 下一级文件夹 = 一个知识库），三种信息组织方式。点卡片看可交互原型。
A · 数据栏 + 库卡片
顶部一排统计（库/笔记/素材/本周/已绑飞书），下面是库卡片网格 + 最近编辑。最接近现在的总览，改动最小。
上手最快信息密度中适合 5–20 个库
打开 A
B · 左列表 + 右详情
左边库列表（含搜索/新建），右边是选中库的详情页：统计、最近文档、快捷操作（关联飞书 / 打开树 / 发布）。
库多也不乱接近桌面工具改动中等
打开 B
C · 活动仪表盘
以“最近在做什么”为主线：本周活动流（新增/修改/同步）+ 紧凑库卡片 + 飞书绑定 + 素材占用告警。
最有“活着”的感觉信息最多改动最大
打开 C

三者的取舍（一句话）

维度A 数据栏+卡片B 左列表+右详情C 活动仪表盘
回答的问题“我有几个库、各多大”“这个库里有什么、能做什么”“这周我动了什么、哪里要处理”
库很多时（20+）卡片会很长最好（可滚动列表 + 搜索）卡片区会被压缩
落地代价最小（现成总览换个容器）中（多一个详情区 + 选中态）大（要 `mtime` 聚合出活动流）
依赖的数据kbs + 计数kbs + 每库最近文档kbs + 近 7 天变更（需扫描/快照）
我的建议：A 先落地（一天内可上），把 B 的“右详情”作为 A 点开库后的过渡页；C 的“本周活动”数据先只做“最近更新 Top N”，等索引快照稳了再上时间线。
