设计说明 · C 分栏聚焦（与现有框架的对应关系）
项说明
定位把主页做成桌面工具：左目录 / 右详情。直接对齐 doc/workbench-authoring-standard.md 的 Pane × Surface 与 wb-split / wb-pane-left / wb-pane-right 骨架。
信息架构左栏三段：工作台（8，可搜索）/ 最近会话 / 已固定；右栏三页签：概览（选中项详情 + 全局概览 + 最近文档 + 快捷操作）/ 会话 / 遥测。
复用 widgetworkbench（改成左栏列表）、kpi（缩小成全局概览 4 格）、sessions、usage、diag；workspaces / clock / pomodoro 收进画廊待加。
新增① 选中态（一次只选一项，刷新后保留需落盘，走现有 layout.json 的 settings 即可，不必扩桥）；② 每模块的「最近项 / 统计」—— 建议一期只做 catalog.js 已有的计数，别在这里开跨模块取数的口子。
侧栏兼容最好：点顶栏「预览 320px 侧栏」会把画布收成 330px，@container (max-width:760px) 立刻把两栏堆叠、KPI 降为 2 列。用容器查询而非 @media，因为侧栏与编辑区同窗不同宽。
落地代价 / 风险中偏大：多一层选中态与一块详情区；宽屏且模块少时右区会显空，需要给「全局概览」留足内容。建议先只做「工作台 + 会话」两段的详情。

原型里点左栏工作台会实时更新右栏的标题 / 描述 / 路由 / 计数与图标；左栏搜索框过滤所有条目。机器锚点仍应放在与布局无关的隐藏 meta 块里（renderDashboardPage() 里的 metaBlock），不要挂在选中项上。
