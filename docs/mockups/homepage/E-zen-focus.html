设计说明 · E 极简聚焦（与现有框架的对应关系）
项说明
定位不是替换默认主页，而是第 2 套可切换的布局预设：zen。给只想「立刻开工」的人一个不打扰的入口。
信息架构一个命令框 + 3 条最近会话 + 一行常用工作台 + 一条安静的状态栏。KPI / 用量 / 诊断 / 工作区全部不放置（组件仍在目录里，可加回）。
复用 widget只用 sessions（config.limit=3）与 workbench（改成 chip 形态）；clock 融进页头，状态栏直接读 summary / tally / tokenLine。零新增组件，只需 2 个呈现变体。
新增命令框需要一套命令路由（/kb 等深链 → openModulePage；搜索 → 会话标题过滤；新建 → newChat）。桥里已有这些具名命令，不用扩协议。
落地代价中：主要是「预设」能力（layout.js 已支持多套 presets 与 active）＋ 2 个组件的紧凑变体。app.jsx 的画廊/编排/保存逻辑完全不用动。
风险老用户会找不到 KPI，别设为默认；命令框若没有真实路由，会变成最扎眼的假控件 —— 上线前必须把每条命令接实。「专注模式」隐藏 IDE 外壳只是演示，真实版应走宿主窗口命令，别在页面里自造全屏。

原型里 ⌘K / Ctrl+K 聚焦命令框，Esc 失焦；「专注模式」会隐藏活动栏与标题栏，右上角保留退出与主题切换。窄容器下字号与间距按 @container 收紧，320px 侧栏仍可用。
