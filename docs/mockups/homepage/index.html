五个方案共同遵守的框架约束（不是随便画的）

  • 颜色只走 --dsw-alias-*（写成 var(--dsw-alias-x, 兜底)），间距/圆角/字号走 --wb-* 刻度。
  • 网格按 lib/layout.js 的 12 列设计，并按容器宽度降列 12→8→4（@container，不用 @media）—— 断点 320 / 520 / 760。
  • 卡片一一对应 lib/catalog.js 的 8 个 widget：kpi / diag / sessions / workbench / workspaces / usage / clock / pomodoro。
  • 工作台磁贴只列 VISIBLE_WORKBENCH_MODULES 里 未下线的 8 个路由；offline: true 的不出卡。
  • 机器可断言的 data-vssaros-dashboard-* 继续由隐藏 meta 块无条件渲染，与用户编排解耦。
  • 图标用内联 SVG（落地可换 wbIconEmoji() 的 emoji 映射）；不用 codicon 字体。
  • 交互：焦点环、cursor:pointer、150–300ms 过渡、prefers-reduced-motion、深浅两色对比 ≥ 4.5:1。
  • 纯静态单页、零外部 CDN（IDE webview 常离线）；本次只做设计评审，不改任何生产代码。
