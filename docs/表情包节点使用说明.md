# 表情包节点使用说明

本文档覆盖工作流画布中的两个表情包节点：**静态表情包**（`ComfyTV.StatEmojiStage`）与**动态表情包**（`Saros.AnimatedEmoji`）。两者通常串联使用：静态节点产出透明贴纸图集，动态节点把每张贴纸变成循环播放的动图 GIF。

---

## 一、静态表情包节点（ComfyTV.StatEmojiStage）

### 简介

静态表情包节点基于 LLM 图像生成能力，按用户描述的**一组表情动作**批量生成 `m × n` 的表情图集（如 3×3 = 9 个表情），并自动切分为单格透明贴纸。它是动态表情包节点的标准上游：先在这里定稿一组静态表情，再交给动态节点逐格「动起来」。

核心能力：

- LLM 生成整版图集（每格一个表情，共享同一角色形象）
- 本地切分为单格（支持裁剪框微调取景）
- 三种切分抠图方式（不抠图 / 绿幕 / 白底几何）
- 单格级编辑：双击裁剪、擦除、单格重生成
- 整版去背景（绿幕 / 白底）

### 使用说明

#### 1. 基本链路

```
[LLM 图像节点/开始节点] → (texts 提供角色/表情描述) → 静态表情包节点 → images 输出
```

- 上游 `texts` 输入提供**角色设定与表情描述**（节点主 prompt 留空时自动取上游文本）。
- 运行后产物为逐格透明贴纸（`images` 输出），每格带 `cellIndex` 标识格号。

#### 2. 主要参数

| 参数 | 说明 |
|---|---|
| 行数 rows / 列数 cols | 图集网格规格，如 3×3 生成 9 个表情 |
| 提示词 prompt | 一组表情的动作描述（如「挥手、点头、哭、笑…」），逐格对应 |
| 风格预设 style_preset | 统一画风（die-cut 贴纸描边等） |
| 图集底色 sheet_background | 绿幕 / 白底——决定后续抠图方式 |
| 切分抠图 cutout_mode | **绿幕（推荐）**：提示词自动追加绿幕底约束，切分时按色度抠净，白发/白描边零误伤；**白底几何**：flood-fill 抠白底（仅白底图集可用，边缘较硬）；**不抠图**：纯裁剪保留背景 |
| 相似度 / 去绿边 | 绿幕抠像阈值（默认 0.25 / 0.08，经大量图集验证；相似度越高抠得越净但误伤风险↑） |

#### 3. 网格交互（内嵌编辑器）

- **点击格子**：选中（蓝框），可多选；批量操作只作用于选中格
- **⟳（格子右下角）**：只重新生成该格（不重跑其他格）
- **双击格子**：打开单格编辑器——拖拽/缩放裁剪框调整取景，应用后直接替换该格产物（不重新生成）；支持橡皮擦擦除像素
- **「调整裁剪」**：对整版图集重裁（`run_scope='recrop'`，跳过生成直接按裁剪框重切）

#### 4. 运行语义

| 操作 | 行为 |
|---|---|
| 卡片「生成」按钮（无选中） | 全部格重新生成 |
| 选中格后点「生成」 | 只重新生成选中格 |
| 应用裁剪 | 跳过生成，按裁剪框重切现有图集 |

#### 5. 去背景

「去背景」按钮对**整版图集**做本地抠图（毫秒级、无需引擎）：

- **绿幕色度**：自动采样四边幕布色抠净（须绿色主导）
- **白底几何**：flood-fill 抠白底

## 二、动态表情包节点（Saros.AnimatedEmoji）

### 简介

动态表情包节点把上游的**静态透明贴纸逐格变成动图**：每格独立「图生视频」（先合成绿幕底喂给视频模型，生成角色做该表情动作的短片），再对视频逐帧绿幕抠像，编码为**透明背景 GIF**（微信表情规范：240×240、≤500KB、循环播放）。

核心能力：

- 双生成渠道：Provider 云端视频模型 / ComfyUI 本地视频工作流（I2V）
- 逐格独立生成与抠像，互不干扰
- 绿幕合成、抠像、GIF 输出三步可独立开关
- 单格重抠图（不重新生成视频，秒级调参）
- 首尾回环混合（循环播放无缝）
- 原片自动固化本地 + 落盘媒体库（不受签名 URL 过期影响）

### 使用说明

#### 1. 基本链路

```
静态表情包节点（images） → 动态表情包节点 → animations / images 输出
```

- 上游 `images` 为逐格透明贴纸（静态表情包节点的产物）；上游为整版图集时自动按 rows×cols 切格。
- 引入上游图片后，网格**每格即时显示该格原图**（白底弱化态），生成后自动被 GIF 覆盖。

#### 2. 生成渠道

| 渠道 | 说明 |
|---|---|
| Provider | 云端视频模型（provider/model 下拉，按 supportsVideoGen 过滤），无需 ComfyUI |
| ComfyUI | 本地视频工作流（I2V），从工作流下拉选择；需 ComfyUI runner 在线 |

#### 3. 主要参数

**GIF 输出页签：**

| 参数 | 说明 |
|---|---|
| 时长 秒 | 单格视频时长（2-5s） |
| 帧率 fps | 抽帧帧率（6-15） |
| 单图上限 KB | 单个 GIF 体积上限（**默认 500 = 微信规范上限**；100 会导致降到 24 色 4fps 且仍超限，颜色偏差明显） |
| 转 GIF 输出 | 关闭后直接以生成的视频为产物（绿幕开=绿幕原片 mp4） |
| 首尾回环混合 | 尾部 4 帧渐回首帧，循环播放无缝（默认开；大动作表情如见鬼影可关） |

**绿幕抠像页签：**

| 参数 | 说明 |
|---|---|
| 幕布色 | **auto（推荐）**：首帧四边自动采样实际幕布色（视频编码会使绿漂移，采样比固定 hex 稳） |
| 算法 | RGB 色距（默认）/ 泛洪连通（主体内部绿色零误伤）/ YCbCr 色度 |
| 相似度 | 主抠阈值，**默认 0.25**（与静态表情包切分同款基准）。宁小勿大：欠抠可调参补救，误抠直接破坏主体 |
| 去绿边 | 边缘 despill 带宽，默认 0.08 |
| 绿幕合成 / 抠像 / GIF 输出 | 三个开关独立：合成关=原图直喂视频模型；抠像关=带背景 GIF；GIF 关=输出视频 |

#### 4. 表情网格交互（内嵌编辑器）

- **点击格子**：选中（蓝框，可多选）；批量按钮只作用于选中格
- **⟳（格子右下角）**：**重新抠图 + GIF**——不重新生成视频，用该格已归档的原片按**当前抠像参数**直接重抠，秒级完成（调参迭代专用）。前提：该格已完整生成过一次
- **右上角模式切换**（四态循环：🎞 GIF → ✂️ 抠像 → 🎬 原片 → 🖼 原图）：
  - **抠图 GIF**：最终产物（1-bit 透明）
  - **抠像预览**：当前参数对原片逐帧抠像的**序列帧**（全彩 + 真透明 PNG，不受 GIF 色数量化损失），底部 ‹ N/M › 翻帧；调参数自动重算
  - **原始视频**：绿幕原片播放（对比抠像效果）
  - **输入原图**：上游静态贴纸
- **主按钮「生成动态表情[n]」**：选中格**完整重生成**（视频 → 抠像 → GIF）；全不选 = 生成全部
- **卡片「生成全部动态表情」**：全量重生成

#### 5. 调参工作流（推荐）

```
① 生成一轮（主按钮/全部）
② 切「✂️ 抠像预览」逐帧检查边缘 → 不满意调 相似度/去绿边/算法
③ ⟳ 单格重抠图（秒级）验证效果
④ 满意后选中其余格批量「生成动态表情」
```

> 原片在生成时已固化到本地并落盘媒体库——⟳ 重抠图不受原片签名 URL 过期影响；即使快照里是已过期的外网 URL，也会自动回退媒体库本地副本。

#### 6. 产物规格（微信表情开放平台对齐）

| 项 | 规格 |
|---|---|
| 动态表情 GIF | 240×240、≤500KB（默认上限）、循环播放、首尾回环 |
| 逐格缩略图 | PNG 240×240 ≤60KB（随产物 meta.thumb） |
| 聊天面板图标 | 50×50 PNG ≤100KB（另制） |

#### 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 颜色偏差 / 描边模糊 | GIF 色数量化（上限太低 → 降到 24-48 色）。把上限调到 500KB 落点 128 色 |
| 边缘锯齿 | 已启用 2× 超采样 + 距离场预滤波；残余为 1-bit alpha 物理极限，可切「抠像预览」看理想效果 |
| ⟳ 报「没有已生成的视频」 | 该格从未完整生成过——先主按钮完整生成一次 |
| ⟳ 报 403 | 原片为旧机制生成的外网 URL 且已过期、媒体库无副本——重新生成一次即可（新原片自动固化） |
| 想保留原视频 | 关「转 GIF 输出」→ 产物为绿幕原片 mp4（自动落盘媒体库） |

---

## 三、推荐完整工作流

```
① 开始/文本节点：写角色设定
② 静态表情包节点：rows×cols + 表情描述 → 生成 → 切分抠图（绿幕）→ 单格微调定稿
③ 动态表情包节点：选渠道 → 生成全部 → ✂️ 抠像预览调参 → ⟳ 逐格精修
④ 输出：透明 GIF（≤500KB）+ 缩略图 PNG，上传微信表情开放平台
```
