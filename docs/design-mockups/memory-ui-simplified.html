改了什么

  • 10 个文件页签 → 3 个作用域组（本项目 / 全局 / Bot）+ 一个「已归档」折叠区。9+1 条物理轨和目录名 projects/<hash>/ 完全不动，零迁移。
  • 25 个平铺开关 → 5 个常用 + 高级折叠。每项带「运行时 / 仅 config.yaml / 只读」徽标，消除「改了没生效」。
  • 两个数字输入 → 一条预算进度条：1,106 / 2,048，抄 Hermes 的 [67% — 1,474/2,200 chars] 与 ds-bot 的 1,240 of 4,000 characters。
  • 独立功能 Tab → 一条待确认横幅：全部采纳 / 全部拒绝 / 10 秒撤销。
  • 作用域条只有一行：一个根选择器 + 全局 / Bot 切换。切换只影响查看；写入目标在输入前显式选一次。没有统计卡、三栏检查器、冲突面板。

刻意不做

  • 不做跨根自动注入（污染上下文）；聚合视图只读。
  • 不新建 /x/memory/ 工作台整页——会触发 dshModuleContainers 清单守卫，且真实入口就是会话页 Tab。
  • 不把 bot × root 做成物理组合键（N×M 目录爆炸）；作用域是标签 + 读取时过滤。
  • 不删数据、不改分区键、不动 keyWriteMode 之外的写入语义；multiRootScopeEnabled:false 可一键退回旧 UI。
