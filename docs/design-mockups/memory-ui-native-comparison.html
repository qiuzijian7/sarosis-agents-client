✓ Hermes：极简到近乎没有 UI

  • 优点：两个文件、一个 6 字段分类页；2,200/1,375 硬上限逼迫精选；冻结快照保护 prefix cache；字符占用直接写进 system prompt，模型自己知道预算。
  • 优点：write_approval 一键把自动学习改成人工审批，--profile 做隔离，概念少。
  • 缺点：无可视化编辑，排错只能 cat 文件 / /memory pending；条目一多只能靠模型自己合并，用户看不到合并过程。
  • 缺点：上限是「写失败再让模型腾空间」，对非技术用户不友好。

✓ OpenClaw：文件即真相

  • 优点：「The model only remembers what gets saved to disk; there is no hidden state」，所有记忆是可读 Markdown，workspace 本身就是 UI。
  • 优点：分层清楚（USER 稳定画像 / MEMORY 精炼事实 / daily 工作层 / DREAMS 人工复核），/context list 把注入截断显式化。
  • 缺点：本机 2026.2.9 里 Memory 只是工具组，没有记忆浏览页；配置散在 JSON、CLI、插件设置三处。
  • 缺点：新版补了 Memory settings / Import Memory / Dreams / Wiki 后，概念量在快速增长，有重蹈 dsh 覆辙的风险。

! dsh：能力最全，界面最重

  • 优点：唯一把「待确认 / 归档 / 移回 / 分支范围 / 项目徽标 / Bot 归属 / 注入预算」都做成可见控件的方案，可审计性最强；9+1 轨覆盖最细。
  • 缺点：10 个文件页签 + 25 个开关 + 12 个会话 Tab，用户要先理解「轨」的概念才能找到一条记忆；作用域信息散在 11px 徽标里。
  • 缺点：设置是单列开关流、无分组；multiRootScopeEnabled / keyBranchFilter 不在 RUNTIME_KEYS 里（改不到），keyWriteMode / botMemoryCharLimit 在 RUNTIME_KEYS 却没渲染控件——用户可见性和可操作性不一致。
  • 缺点：新增的 ScopeBar 只在多根时出现，单根退回裸 cwd 文本，根 chip 不可点，作用域层级反而更深了。

✓ ds-bot：一行入口 + 三层下钻

  • 优点：Bot 设置里只有「12 entries → Manage」一行；点开是 summary / All entries / Change history 三页，底部一个 Ask or update 输入框同时承担读写。
  • 优点：限额（entry 300 / main 4,000 / topic 16,000 / topics 40）硬编码不暴露；own / team / group 在面板内用 section 表达，配置负担为零。
  • 缺点：几乎没有可调项，无法按项目/分支调预算；无多工作区作用域概念（Bot 就是唯一分区键）。
  • 缺点：Change history 靠 journal.jsonl，不是 Git；跨设备同步要靠自己拷目录。

针对「记忆页面太复杂了」的简化建议（按投入从小到大）

  1. 先减页签，不减数据。把 10 个文件页签收成 3 组（全局 / 本项目 / Bot），归档轨收进组内「已归档」折叠区；保留 9+1 轨的物理分区不变，零数据迁移。对标 ds-bot 的「一行入口 + 三层下钻」。
  2. 设置页按「写入 / 注入 / 高级」三组卡片化。25 个开关默认只露 5 个常用的（后台审查、keyWriteMode、写入看门狗、Bot 预算、同步），其余折进「高级」；把「运行时可改 / 仅 config.yaml / 只读指标」做成徽标，消除「改了没生效」。
  3. 把预算做成一条进度条，而不是两个数字输入。抄 Hermes 的 [67% — 1,474/2,200 chars] 与 ds-bot 的 1,240 of 4,000 characters：用户只需知道「快满了」，不必理解阈值算法。
  4. 把确认队列收成一个横幅。待确认建议不用单独功能 Tab，用「4 条待确认 · 全部采纳 / 全部拒绝 / 10 秒撤销」；采纳按钮直接写明目标轨与根。
  5. 作用域从「徽标」升级为「可切换的单一上下文」。单根时保持现在的极简；多根时只有一个根选择器 + 一个「全局 / Bot」切换，切换只影响查看，写入目标在输入前显式选一次。不要再做统计卡、三栏检查器、冲突面板。
  6. 一句话验收：新用户不看指南，能在 3 次点击内找到「我上次让 AI 记住的那条」，并在 1 次点击内改掉它。
