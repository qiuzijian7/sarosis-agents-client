❓ 九、常见问题

安装 Skill 后，在 Skill 列表中找不到？▾
安装成功后需要重新加载窗口。按 Ctrl+Shift+P，输入 Developer: Reload Window，或关闭并重新打开 vsSarosis。
发布资源时提示「版本已存在」？▾
同一资源的同一版本只能发布一次。请发布新版本（如从 1.0.0 升到 1.1.0）。
下载速度很慢？▾
检查商城服务端的网络连接，或在设置中修改商城地址为更近的服务器。
安装 MCP 后无法在集成视图中找到？▾
当前版本需要手动导入 MCP 配置。请参考第四节 4.3 中的说明，运行 MCP: Install Server 或在集成视图中手动添加。
如何删除已发布的资源？▾
在商城网页版（http://21.6.92.5:3040）登录 → 进入「我的资源」→ 找到资源 → 点击「删除」。注意：删除会同时删除所有版本且无法恢复。

💻 十、API 调用示例（开发者参考）

在代码中通过 IMarketplaceService 调用商城功能：

// 获取 MarketplaceService 实例 const marketplace = accessor.get(IMarketplaceService); // 登录 await marketplace.login('admin', 'admin123'); // 搜索 Skill const result = await marketplace.listPackages({ kind: 'skill', search: 'pdf', pageSize: 10 }); // 下载并安装 await marketplace.download('pdf-skill', '1.0.0', 'skill'); // 发布资源 await marketplace.publish('my-skill', 'skill', { changelog: '初始版本' }); // 检查更新 const updates = await marketplace.checkUpgrades([ { kind: 'skill', storeId: 'pdf-skill', version: '1.0.0' }, ]);

资源包格式 (manifest.json)

{ "id": "pdf-skill", "kind": "skill", "name": "PDF Skill", "version": "1.0.0", "description": "用于处理 PDF 文件的技能", "author": "admin", "tags": ["pdf", "document"], "files": ["SKILL.md", "README.md"] }
