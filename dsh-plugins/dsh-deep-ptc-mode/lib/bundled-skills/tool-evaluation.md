# Agent 工具实效评测

适用于工具已经能调用，但需要判断模型能否选对工具、补齐参数并完成任务。准备一组固定、可重新创建的输入，保留机器能核对的期望结果；使用该 Agent 实际能看见的说明和工具入口。

例：测试项目卡读取时，造两张同标题、不同 ID 的卡，其中一张改过版本。给模型自然语言任务「找出目前生效的约定，给我条目编号和依据」，让评分程序分别检查卡 ID、条目 ID、版本与内容。不在问题里提示工具名。

- 每个案例记录输入、初始状态、允许的工具和验收谓词。覆盖正常任务、歧义、缺少信息、空结果，以及一次失败后的恢复。涉及写入时使用可重置的假数据。
- 对照旧版和新版时固定模型、设置、可用工具、测试数据；每个案例开新会话。记录完成次数/运行次数和调用轨迹。模型有随机性；一次跑绿只是一条样本。
- 把失败归到首次偏离处：未发现工具、选错对象、参数错误、结果缺字段、错误解释，或工具实现错误。针对该处修正后重跑相同案例。
- 交付案例表、验证方式、两版结果和一个有代表性的失败轨迹。静态 schema 检查、模拟调用、真实模型运行分别标注。

参考 [Anthropic MCP 工具评测指南](https://github.com/anthropics/skills/blob/main/skills/mcp-builder/reference/evaluation.md)。
