三个方案的取舍

 V1 全量页签V2 上下分屏V3 卡片+折叠
覆盖清单7 页签全覆盖3 页签 + 常驻两块折叠面板全覆盖
“用户看到什么”人设页签里可放预览看不到顶部常驻
工具勾选（清单 B4）独立页签，空间大上半区，空间中折叠区内，空间中
切页签次数多（7 个）少中（折叠）
字段继续变多最好扩展（加页签）上半区会挤加折叠项即可
实现成本中中低（折叠面板最省）
共同点（三个方案都遵守）：
· 左栏只做“选谁”，顶部固定 计数 / 筛选 / 刷新，底部 ＋Bot / ＋群聊。
· 内置 agent 的提示词标只读（真源 builtinAgents.ts），避免“改了产物以为生效”。
· 白名单用勾选，未选项灰显 —— 手填名字拼错会让 allowlist 静默 deny。
· 建议词校验：≤3 条、禁半角逗号（会被 parseFrontmatter 切成两条）。
· 不做假 chat：会话只列、点击跳会话页；版本/分支标注“在完整页”。
· 用量 / 委派总览 / 授权 是全局页签，放独立编辑器 Tab，不塞进单 agent 详情。
