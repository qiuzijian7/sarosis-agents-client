我的建议：A 作默认，C 作「维护」页

  • 记忆库的主场景是右栏常驻 + 快速清掉待审，A 的 2 步流程最省事，也不会再把标题挤成竖排。
  • C 的卡片别丢：把它放进「维护」页签，正好承载漏斗、归档、运行时三件「偶尔看」的事（顺带解决现在主页一条长滚动的问题）。
  • B 只在「中栏全宽」时才值得——可以作为宽栏的增强版渐进上线，不必一开始就做。

确认方式（回一个字母即可）

  • A 只做 A；B 只做 B；C 只做 C。
  • A+C = 主页 A + 维护页 C（推荐）。
  • 也可以说「A 但要 就地详情」这类微调，我按你的话改。
