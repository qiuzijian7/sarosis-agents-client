Main Loop Sequence

agentTurnExecutor.ts :: executeAgentTurnDirect()

Phase: Initialization
Init→Init create turn AbortController per turnKey(sessionId::agentId)
Init→Init AgentLoopStrategyFactory.resolve() → HermesReActStrategy (default)
Init→Init IterationBudget(90) + restore from checkpoint if resume
Phase: Pre-loop Orchestration
Init→strategy.preLoop() assessFn: LLM decides if exploration needed
alt [needsExploration]
PreLoop→PreLoopexploreFn: dispatchParallelExplore() — spawn N code-explorer sub-agents
PreLoop→PreLoopaggregate findings → inject as context into messages
PreLoop→PreLoopplanGenerator: LLM generates ParsedPlanTask[] from findings
PreLoop--→Init return { planTasks[], findings }
Phase: while(iteration < MAX_TOOL_ITERATIONS) — per-iteration loop
Loop→Loop check turnAbortSignal.aborted (V3: explicit abort checkpoint)
Step 1: Context Compression
Loop→CompresspruneOldToolOutputs() — cheap head+tail truncation
Loop→Compresscheck cooldown (COMPRESSION_COOLDOWN_MS)
Loop→Compressif tokens > window*30% && msgs ≥ min: compressContext()
Step 2: Tool Assembly
Loop→AssemblygetEnabledTools() + ToolSearch bridge expansion
Loop→AssemblybuildForkContext() for prefix-cache alignment
Step 3: LLM Call
Loop→modelProvider.chat(modelId, messages, tools) [conversationId + requestId + previousResponseId]
modelProvider--→Loopfor-await stream delta (text / thinking / tool_call / usage / error)
Loop→Loopon error: transient retry with exponential backoff; TimeoutError thrown upward
Step 4: Post-process LLM Response
Loop→Loopwhitelist filter (hallucination guard) + repair deprecated names + dedup + phantom filter
alt [no tool calls]
Loop→LoopclassifyIncompleteTurn(empty/reasoning-only/length) → safe retry or continue
Loop→LoopPlan-Execute-Reflect: if hasModifiedFiles, inject reflect prompt → continue
Loop→Loopadvance planTasks queue: if next task exists → inject reminder → continue
Loop→Loopyield {type:'done'} → break [normal termination]
Step 5: Tool Execution [has tool calls]
Loop→ToolExechardPermission intercept (plan mode: write tools blocked)
Loop→ToolExecTool Call Loop Detection (same params 3x → anti-loop reminder)
Loop→ToolExecsplit serverExecuted (skip local) vs localExecuted
Loop→ToolExecsandbox confirmation dialog (security violation → pause loop)
Loop→ToolExecparallel (ParallelToolExecutor) or serial execution
ToolExec--→Loopreturn toolResults[]
End of Iteration
Loop→State budget.consume(1) [or refund(1) for delegation rounds]
Loop→State V3: checkpoint persist every 3 iterations (budget + messages + runState snapshot)
Loop Exit
Loop→Loop yield {type:'done'} (MAX_TOOL_ITERATIONS reached)
Loop→State storeTurnObservations (retrieval-based context externalization)

Pre-loop Orchestration

preLoopOrchestrator.ts

strategy.preLoop() → preLoopOrchestrate(userMessage, deps)
Step 1: LLM Autonomous Assessment — assessFn(userMessage)
preLoop→assessFn Lightweight LLM call: needsExploration? explorationAreas[]? planTasks[]?
assessFn--→preLoop PreLoopAssessment { needsExploration, explorationAreas[], planTasks[], reason }
alt [needsExploration == false]
preLoop→strategyreturn { planTasks, assessment } — directly into main loop
alt [needsExploration == true]
Step 2: Parallel Exploration — exploreFn(areas[], goal)
preLoop→exploreFndispatchParallelExplore(): spawn N code-explorer sub-agents
exploreFn--→preLoop{ findings (aggregated text), successCount, failCount }
Step 3: Plan Generation — planGenerator(userMessage, findings)
preLoop→planGeneratorLLM generates structured tasks from user intent + exploration findings
planGenerator--→preLoopParsedPlanTask[] (title, description, deps, filePaths)
preLoop→strategyreturn { planTasks[], findings, assessment }
Fallback: assessFn fails → original loop; exploreFn fails → no findings; planGenerator fails → use assessment.planTasks
