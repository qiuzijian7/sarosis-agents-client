## 3. 差异与优缺点

| 维度 | dsh-open-market | 本项目商城 | 优化取舍 |
| --- | --- | --- | --- |
| 产品定位 | DSH 社区插件目录及管理 | Agent、Skill、MCP、工作台、知识库、插件；支持组合资源及发布审核 | 保留全部真实品类，不恢复 workflow 商品类型 |
| 发现首页 | 今日推荐、榜单、横向推荐区、全部插件 | 工具栏、类型/分类、已安装折叠、商品网格 | 增加最近更新横排与下载最多榜；搜索时单独显示结果 |
| 信息密度 | 约 220px 横排卡片；图标、两行简介、状态与快捷动作 | 默认最小宽度 340px、三行简介、封面及 Bot 摘要 | 推荐卡片紧凑；搜索结果保留小/中/大尺寸 |
| 收藏 | 收藏分组、导入导出、profile 持久化 | 没有收藏 UI | 增加独立收藏清单，以 kind:slug 为身份 |
| 详情 | 居中弹窗，按需截图/版本/更新说明 | 约 560px 右抽屉，封面、正文、版本与作者操作 | 商品详情改宽弹窗；发布、配置保留任务型抽屉 |
| 本地管理 | 列表/详情分栏、启停/更新/异常过滤、诊断与队列入口 | 已安装页签、类型折叠、本地资源发布、MCP 配置及开关 | 用分栏组织现有能力；诊断、队列另行核验 |
| 数据获取 | 汇集完整目录；IndexedDB 缓存；6 小时刷新；版本按需读取/去重 | 服务端分页；列表后串行读取安装清单与 MCP 状态 | 保留分页，用有界缓存、并行只读请求与共享安装索引 |
| 搜索 | 分类、作者/描述及同义词匹配 | 名称、介绍、slug；按 Enter 提交 | 首版改善提交/清除/状态，完整搜索能力后端另期扩展 |
| 反馈与无障碍 | 按项忙碌；焦点管理、aria-modal、减少动态效果 | 页面全局 busy；抽屉缺完整焦点闭环 | 按商品同步 pending，补键盘、焦点恢复和请求代次 |
| 安全与恢复 | 调宿主检查安装；声明任务守卫、更新失败恢复 | 安装预览、校验、路径保护、便携包、发布空商品回滚 | 复用本项目安全链，不能仅因上游 UI 有按钮就搬入执行能力 |
| 主题与隐私 | 可选装饰主题覆盖整个 DSH；匿名计数始终开启 | 独立页面及窗口明暗归属；官方助手停靠 | 装饰主题只作用商城，不发上游计数、不自动改审批模式 |

### 上游值得借鉴

- 浏览、搜索、收藏、管理分开；没有把所有维护按钮平铺在页头。
- 图标与名称优先，分区紧凑，横向浏览与榜单提供清晰探索路径。
- 版本和截图按需读取，卡片与详情共享操作反馈。
- 弹窗包含焦点圈定/恢复、Esc 关闭与语义标识。

### 上游不宜照搬

- 客户端约 3918 行，缓存、主题、管理与 UI 耦合，不是理想拆分模板。
- 首次汇集完整目录的策略不适合本项目较大、多品类目录。
- 原生插件管理与本项目资源落盘机制不同，不能照搬版本切换、启停或空闲队列实现。
- 全局装饰主题、默认匿名计数和自动审查小工具超出商城职责。
- 粗线和硬阴影可能压过正文，装饰层不能降低可读性或改变布局尺寸。

### 本项目优点与待改问题

- **优点**：资源范围完整；Host 自持认证与安装；安装前检查、SHA-256、技能原文保留；发布审核、私有资源、便携包与唯一官方助手。
- **问题**：页头工具拥挤；缺收藏/发现层；已安装隐藏与总数口径不同；分类只有已加载页；全局 busy 与旧请求覆盖风险；详情宽度和版本操作层级不足。
- **字段欠账**：`shape.js` 没有统一传递下载数、可安装性及时间；推荐 UI 必须先补同一真源，不能造指标。

## 4. 原型范围与可试交互

按用户 2026-11-14 新要求，原型改为单文件、无依赖、**只读获取真实公开商城数据**的 HTML。商品名称、介绍、作者、版本、下载量、图标/Logo、缩略图均直接来自 `http://21.91.158.20:3040/api/v1/packages`；详情与版本按需读取公开接口。图片使用接口原地址，不生成、不染色、不用虚构图片替代。

没有图片的商品如实显示“无图标 / 商城未提供缩略图”；失效原图显示加载失败，并可从详情打开原始链接。本机安装状态、私有发布和审核队列没有读取，不能当作真实；收藏与安装/发布操作仍仅为页面内存示意，不触碰账号、Host、用户资源或线上数据。需要能够访问内网商城及原图地址。

可试：

1. 原生/装饰 × 浅色/深色；皮肤只改变商城业务区，助手皮肤不随之变化。
2. 已安装、发现、收藏、我的发布及审核导航；已安装置于最前，默认打开页仍为发现；类型筛选、搜索、排序和尺寸选择。
3. 收藏、分组选择、新建/重命名/删除分组、导入/导出清单的 UI 示意。
4. 宽详情、版本记录、安装前检查、按项模拟安装反馈、任务型发布抽屉。
5. 已安装分栏；窄容器切成列表到详情的返回式导航。
6. 助手开合、编辑草稿；切换主题/导航不销毁助手节点。
7. 加载、空态、失败、离线及重试；全部可从原型控制栏切换。

原型不是真实宿主组件，不证明生产助手、MCP、安装或发布功能可用。后续生产实现继续使用宿主唯一 `props.conversation`，不会采用原型示意聊天框。

## 5. 双主题设计

- **原生**：沿用 VsSaros 语义色与系统字体；14px 工作台标题、13px 正文；轻边框、8–12px 圆角。
- **装饰**：同一组件叠加低饱和色块、墨线和短硬阴影；深色为夜海配色。原创几何图形，不复制鲸鱼角色。
- **两个维度**：用户切换皮肤；明暗仍服从生产窗口归属。原型提供独立明暗按钮仅供验证，不改宿主配置。
- **作用域**：皮肤变量、样式及浮层限制在商城根内；不覆盖助手、侧栏、其他工作台或全局主题。
- **响应**：根据实际商城容器宽度调整，不只看窗口。搜索区和品类可换行；窄窗口没有主导航横向裁切；弹窗保留视口边距。
- **动态**：手动横排浏览，默认不自动轮播；150–200ms 微反馈，减少动态效果时取消位移和动画。
