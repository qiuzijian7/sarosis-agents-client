# VsSaros 商城使用说明（Mockup 演示版）

> **本文档为模拟演示版本**，描述用户在 VsSaros 客户端中如何通过商城安装、下载、更新 skill/agent/mcp/知识库的完整操作流程。
>
> **前置条件**：
> - 商城服务端已部署（http://21.6.92.5:3040）
> - 客户端已配置商城地址（`设置 > Sarosis > Marketplace Url`）
> - 用户已在商城注册账号

## 一、界面概览

### 1.1 商城入口位置

在 VsSaros 中，商城功能通过以下入口访问：


**商城面板打开方式**：
- 方法 1：点击顶部菜单 `🛒 商城`
- 方法 2：命令面板 `Ctrl+Shift+P` → 输入 `Marketplace: Open`
- 方法 3：在 Agent/Skill/MCP/知识库编辑器中，点击 `🛒 浏览商城` 按钮

## 二、登录商城

### 2.1 首次登录

打开商城面板后，如果未登录，会显示登录界面：

```

│              ┌───────────────────────┐                  │

│              ├───────────────────────┤                  │

│              └───────────────────────┘                  │
│                                                         │
│              ┌───────────────────────┐                  │
│              │  密码                  │                  │
│              ├───────────────────────┤                  │

│                                                         │

│              [ 修改 ]                                    │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**操作步骤**：

1. 输入用户名/邮箱和密码
2. 点击 `登录`
3. 登录成功后，自动跳转到商城首页

**注册新账号**（如果没有账号）：

1. 点击 `注册`
2. 在弹出的表单中填写：
   - 用户名（3-20 字符）
   - 邮箱
   - 密码（至少 6 位）
3. 点击 `注册`
4. 注册成功后会自动登录

### 2.2 登录状态保持

登录后，token 会保存在本地，下次打开商城面板会自动登录。

**退出登录**：点击商城面板右上角的用户头像 → `退出登录`

### 4.2 安装 Agent

安装 Agent 类型资源的流程类似，但会额外执行：

1. 下载 `agent.json` 和引导文件（`.agent.md`）
2. 调用 `IAgentStudioService.createAgent()` 创建 Agent
3. 写入 `~/.saros/custom-agents.json`
4. 在 Agent 列表中显示新安装的 Agent

**安装完成后**：新 Agent 会出现在 `Agent Studio` 面板中。

### 4.3 安装 MCP

安装 MCP 类型资源时：

1. 下载 `config.json`（MCP 服务器配置）
2. 复制到 `~/.saros/mcp-servers/{id}/config.json`
3. **提示用户手动导入**：

```

│  ⚠️ 需要手动操作                                        │

│  [ 复制配置 ]    [ 打开集成视图 ]    [ 关闭 ]          │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

> **说明**：MCP 的完整自动注册功能将在后续版本中实现。

1. 下载 `docs/` 目录和 `index.json`

发布 Agent 的流程类似，但会自动打包以下内容：

- `agent.json`（Agent 定义）
- `.agent.md`（引导文件）
- 相关配置文件

### 6.3 发布新版本

如果资源已经发布，可以在 `我的资源` → `编辑` 中发布新版本：

1. 打开已发布的资源
2. 点击 `发布新版本`
3. 填写新版本号（语义化版本，如 `1.1.0`）
4. 上传新版本文件
5. 填写更新日志
6. 点击 `发布新版本`

## 七、更新资源

### 7.1 自动检查更新

如果启用了 `自动检查更新` 设置：

- VsSaros 启动时会自动检查已安装资源的更新
- 如果有可用更新，会在右下角显示通知：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  🔔 有 3 个资源有可用更新                              │
│                                                         │
│  - PDF Skill: 1.0.0 → 1.1.0                          │
│  - Code Review Skill: 1.0.0 → 1.2.0                  │
│  - Deep Researcher: 1.1.0 → 1.2.0                    │
│                                                         │
│  [ 查看详情 ]    [ 全部更新 ]    [ 忽略 ]             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 7.2 手动检查更新

在商城面板中：

1. 打开 `我的资源` 标签页
2. 点击 `刷新` 按钮
3. 系统会自动检查所有已安装资源的更新
4. 有更新的资源会显示 `更新可用` 标签

### 7.3 更新设置

在 `设置 > Sarosis > Marketplace` 中配置：

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| `Marketplace: Url` | 商城服务端地址 | `http://21.6.92.5:3040` |
| `Marketplace: Auto Check Updates` | 启动时自动检查更新 | `true` |
| `Marketplace: Update Interval` | 更新检查间隔（秒） | `3600` |

## 九、常见问题（FAQ）

### Q1: 安装 Skill 后，在 Skill 列表中找不到？

**A**: 安装成功后，需要重新加载窗口。可以：
- 按 `Ctrl+Shift+P`，输入 `Developer: Reload Window`
- 或关闭并重新打开 VsSaros

### Q2: 发布资源时，提示 "版本已存在"？

**A**: 同一资源的同一版本只能发布一次。如果需要更新，请发布新版本（如从 `1.0.0` 到 `1.1.0`）。

### Q3: 下载速度很慢？

**A**: 可能是网络问题。可以：
- 检查商城服务端的网络连接
- 在设置中修改商城地址为更近的服务器

### Q4: 安装 MCP 后，无法在集成视图中找到？

**A**: 当前版本需要手动导入 MCP 配置。请参考 [第四节 4.3](#43-安装-mcp) 中的说明。

### Q5: 如何删除已发布的资源？

**A**: 在商城网页版（http://21.6.92.5:3040）中：
1. 登录账号
2. 进入 `我的资源`
3. 找到要删除的资源
4. 点击 `删除`

> **注意**：删除资源会同时删除所有版本，且无法恢复。

## 十、附录：API 调用示例（开发者参考）

### 10.1 在代码中调用商城服务

如果你需要在自己的插件或脚本中调用商城 API，可以参考以下示例：

```typescript
// 获取 MarketplaceService 实例
const marketplace = accessor.get(IMarketplaceService);

// 登录
await marketplace.login('admin', 'admin123');

// 搜索 Skill
const result = await marketplace.listPackages({
  kind: 'skill',
  search: 'pdf',
  pageSize: 10,
});

// 下载并安装
await marketplace.download('pdf-skill', '1.0.0', 'skill');

// 发布资源
await marketplace.publish('my-skill', 'skill', {
  changelog: '初始版本发布',
});

// 检查更新
const updates = await marketplace.checkUpgrades([
  { kind: 'skill', storeId: 'pdf-skill', version: '1.0.0' },
]);
```

### 10.2 资源包格式

发布资源时，需要将资源打包为 `.tar.gz` 格式，并包含 `manifest.json`：

```json
{
  "id": "pdf-skill",
  "kind": "skill",
  "name": "PDF Skill",
  "version": "1.0.0",
  "description": "用于处理 PDF 文件的技能",
  "author": "admin",
  "license": "MIT",
  "tags": ["pdf", "document", "extract"],
  "files": ["SKILL.md", "README.md"]
}
```

**各类资源的特殊文件**：

| 资源类型 | 必须包含的文件 | 说明 |
|----------|----------------|------|
| Skill | `SKILL.md` | 技能定义文件（frontmatter + markdown） |
| Agent | `agent.json`, `.agent.md` | Agent 定义 + 引导文件 |
| MCP | `config.json` | MCP 服务器配置 |
| 知识库 | `index.json`, `docs/` | 知识库索引 + 文档目录 |
