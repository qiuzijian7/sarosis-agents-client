D-13 · 修 D-07 时顺带挖出的「静默丢事件」：长连接通了也不代表消息会到 Agent —— 入口只认 im.message.message_received，而飞书 v2 推送的名字是 im.message.receive_v1（官方 SDK onP2MessageReceiveV1）。 这类缺陷的共性是判定条件写死在一个未经真实数据校验的字符串上， 所以修复同时改成「两名字兼容 + 未知消息类事件名记日志」， 让下一次契约漂移表现为一条可读日志，而不是「渠道又不工作了」。
