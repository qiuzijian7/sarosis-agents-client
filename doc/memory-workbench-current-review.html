5. 结论：三个重构方案的出发点

功能深度我们第一，信息架构我们垫底。审核、注入、降级语义这三样已经超过五家；但主页的组织方式还停在「把功能块按开发顺序摞起来」。 因此重构不动后端、不动数据流，只重排 UI：把「今日该做什么 / 记忆里有什么 / 系统健康吗」三层分开，并把五家的成熟件（徽标带、页签计数、位置标签、冻结确认、密度档、诊断页、指南页、可信度字形）逐个接上。 三个方案的区别是信息架构哲学，不是颜色：
R1 收件箱优先——主页 = 今日（审核是第一任务），其余进页签。
R2 仪表盘优先——主页 = 六张卡（一眼看全），审核进二级。
R3 桌面应用骨架——宽屏左侧竖导航 + 主区 + 上下文栏，窄屏退化为顶部分段。 → 看三个方案并排对比
