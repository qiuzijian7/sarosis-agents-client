重构分屏布局主会话
右侧多格要能自由拖动、拆分、关闭，左侧主栏保持全高。
好的。约定如下： · 主栏（含官方侧栏）固定全高，最窄 720px； · 右侧是一棵左右 / 上下嵌套的分格树，每格是一条独立会话； · 拖标题栏到另一格的边缘 = 拆到那一侧，拖到中央 = 交换； · 关闭只收起窗格，会话仍留在左侧工作区，可撤销。
zoneFor(rect, x, y): edge = max(48, min(w, h) * 0.28) 左 / 右 / 上 / 下 边缘带 ⇒ 拆分；中央 ⇒ 交换
试试：拖动右侧任意一格的标题栏，或者点「运行自测」看完整流程。

操作说明

移动 / 拆分

  • 按住某一格的标题栏拖动：拖到另一格的 左 / 右 / 上 / 下边缘 ⇒ 拆到那一侧；拖到 中央 ⇒ 两格交换位置
  • 拖到主栏 ⇒ 不允许（红色提示）；拖动中按 Esc 取消
  • 从左侧工作区把会话拖到右边 ⇒ 在新窗格打开
  • 标题栏按钮：向右拆分 · 向下拆分 · 最大化 · ✕ 关闭；右键标题栏有更多（移到整列 / 整行、平均分配、自动排列、关闭其他）

调整大小

  • 拖格子之间的分隔条（双击 = 均分）；拖主栏右侧的分隔条调主栏宽度（双击 = 复位）
  • 每格至少 200px，主栏至少 720px

快捷键

  • Ctrl+\ 向右拆分当前格 · Ctrl+Shift+\ 向下拆分 · Alt+W 关闭当前格 · Ctrl+Z 撤销

设计约定

  • 「新窗格」切开当前最大的那一格（宽就左右切，高就上下切），不打乱已有布局
  • 关闭后相邻格补位，不自动重排；手动布局永远不会被自动覆盖（「自动排列」需手动触发）
  • 关闭 ≠ 删除会话：会话仍在左侧工作区，误关可「撤销」
