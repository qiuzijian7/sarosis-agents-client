设计要点
• 类型胶囊：替换原空「kind」徽章——LLM / EXEC / CALL / INPUT / OUTPUT / ROUTE 等更直白（用户角度）。
• 核心参数：每个节点只展示 2-3 行关键配置（agent/provider/prompt、name/args、target/分支等），不堆 28 字 JSON 截断。
• JSON chip 化：skillArgs / toolParams / options 等不再裸 `{...}`，拆成 chip 显示具体 key=value。
• 端口颜色：true=绿 / false=红 / case-1..4=蓝/紫/橙/青 / default=灰虚线——远距离可识别分支走向。
• 概要预览：最底部一行小字 mono（带 `{{input}}` 高亮），hover 展开全文，避免卡片过长。
