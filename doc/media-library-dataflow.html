媒体库 · 工作流与数据流

对应 @vssaros/dsh-media 0.7.9（2026-10-27）。一句话：字节始终是**独立文件** （objects/ 内容寻址 + archive/ 可读名硬链接），SQLite 只当索引； 写入侧有五条入口（聊天生图直写 / ComfyUI 推送 / 页面导入 / 链接文件夹 / LightAI 产物回源下载）， 读出侧有页面 / agent / 导出三条出口。

实线 = 字节落盘（复制或硬链接） 数据库 = 元数据行 虚线 = 只记路径（弱引用）/ 通道 紫色 = 页面生成的缓存

库内部：四个落点

media.db（SQLite） 元数据唯一真源：id / sha8 / kind / 尺寸 / 字节数 / file_path / board / tags / note / is_deleted 实测 368KB（667 条）—— 图不在库里
objects/<sha8[0..2]>/<sha8>.ext 字节本体，内容寻址 ⇒ 同图只一份、改名/移动免疫；/api/bytes/<id> 异步读 实测 328 文件 / 323MB
thumbs/<sha8>.webp 256px 缩略图 / 视频海报。Host 无编码器 ⇒ 页面 canvas 生成后回传，缓存命中即免解码
archive/<来源>/<年-月>/<名字>-<sha8前6>.ext 入库即归档的可读副本；同卷**硬链接**（与 objects 同 inode，不占空间） 可用 config.archiveDir 指到别的盘（会真复制）

时序：生成一张图 → 出现在页面 → 已归档

  1. 模型调 generate_image → imagegen 拿到字节（BYOK 经桥回 IDE，或 LightAI 直连）
  2. imagegen 先存工作区一份（attachments.saveImage，用户可见）
  3. 再 vssarosMediaStore.importAsset({bytes}) → 写 objects/<sha8>.ext + 插一行元数据
  4. 同一步里 archiveOne() 给 archive/<来源>/<年-月>/… 建**硬链接**（失败只记账，不影响生图）
  5. 打开着的页面靠 GET api/rev（SQLite total_changes()）发现变更 → 自动 reload，保留选中
  6. 首屏卡片无缩略图 → IntersectionObserver 只对可视附近做：图片缩 256、视频 seek 一帧 → POST api/thumb/<id> 落盘
  7. 用户点「📤 导出到文件夹」→ 同卷硬链接一份到指定目录（幂等，可反复跑）

不变量与坑（都踩过）

  • 图从来不在 SQLite 里：库 368KB vs 字节 323MB。谈“换存储”其实只影响 objects/ 的命名与分层。
  • SSR 是内存快照：改 mediaPage.js 必须重启 Host；app.js 每次请求读磁盘 ⇒ 改它刷新页面即可。
  • 页面不能拿绝对路径：<input webkitdirectory> 不给路径（新版 Electron 无 File.path）⇒ 链接/导出都靠**手填路径**，Host 侧读。
  • 弱引用会烂：链接文件夹的源文件被移走 ⇒ 卡片变字形；这是“引用”而非“副本”的固有代价。
  • 归档失败不报错：只进 usage.archive（ok/copied/failed/lastError）；重试 = 再点一次导出（幂等）。
  • 硬链接跨卷会失败：同卷才 bytes=0；异盘自动退回复制并把占用算出来。
  • 视频别塞 <img>：曾导致 79 条视频各拉整段 + readFileSync 堵死事件循环 ⇒ 切页签卡死。现在 imgUrl 只给“有海报”或“就是图片”。
  • 加工具必须重生成快照：node dsh-plugins/tools-snapshot.mjs --write + check-agent-tools，否则 agent 的 tools 白名单守卫红（名字不认识 = 那个工具被静默摘掉）。

当前缺口（诚实标注）

① 已补（0.7.9）：video_generate / text_to_speech 现在把 LightAI 产物 下载成字节 → 入库 → 自动归档（`importExternalOutput`）。原来它们只回 {url}，库里因此**有图没视频**。 返回里多一个 media:[{id, archivePath}]；下不来就只留 URL（404 / 鉴权 / 超时 / >512MB 都只记 warning，绝不让生成失败）—— 这条有反证探针（p3-107 ⑰d：产物 404 时工具仍 ok:true、media 为空）。
② 老数据不追溯归档：归档只发生在**入库那一刻**。现有 667 条要点一次「📤 导出到文件夹」才会补出来（幂等，随便跑）。
③ 104 条只有外链、没有本地字节（ComfyUI 的 /view?filename=…）：导出时计入 skipped.noFile，预览保持占位字形。
