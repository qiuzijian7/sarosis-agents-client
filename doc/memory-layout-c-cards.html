方案 C · 卡片仪表盘

按「一屏看清五件事」组织：待审 / 注入 / 漏斗 / 归档 / 运行时各一张卡，每张卡只有一个主数字 + 一个动作。窄栏自动单列。

宽度主题状态
记忆库中栏
适合
  • 「这周攒了什么、健康不健康」优先于「现在要审哪一条」。
  • 卡片彼此独立：某个源取不到时只塌一张卡，不会整页空。
代价
  • 审核要进二级（卡片里只露 3 条预览），批量操作藏得比 A/B 深。
  • 窄栏里卡片堆叠，滚动长度最长；卡片边框多了会有「仪表盘噪音」。
来源：卡片 + 单主数字取自 dsh-longterm-memory 的 8 格 Stat 与库路径卡；†/⌊ 可信度字形与阈值脚注取自 dsh-living-memory（`client.js:278-302`：>70% 红、>50% 橙，且把「建议换窗」写进脚注）；「累计 vs 时点」分列是同源结论。
