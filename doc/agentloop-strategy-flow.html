4. HermesReActStrategy — Hook Invocation Timeline

HermesReActStrategy implements IAgentLoopStrategy with 5 hooks, 4 implemented

Phase A: Before the main while() loop — agentTurnExecutor.ts:324-345
Hook: preLoop(ctx) → AsyncGenerator → PreLoopResultMeta
Guard condition: strategy.preLoop && !request.agentId.startsWith('subagent-')
Skips for sub-agents to prevent recursive explosion
StepActionDescription
4.1 buildPreLoopDeps(host, modelProvider, modelId, agentId, signal) Constructs assessFn (LLM call), exploreFn (parallel sub-agent dispatch), planGenerator (LLM call)
4.2 preLoopOrchestrate(userText, deps) assessFn: LLM decides needsExploration
If yes: exploreFn dispatches N parallel code-explorer sub-agents
planGenerator: LLM generates ParsedPlanTask[] from findings
4.3 Return PreLoopResultMeta { preExploreDone, preExploreResult, planTasks[], findings }
4.4 Main loop receives findings injected as system message; planTasks[0] reminder injected; queue advances in while
Fallback: If preLoop throws, caught and returns { preExploreDone: false, planTasks: [] } — zero overhead fallback to direct ReAct loop.
Phase B: Every iteration, before LLM call — agentTurnExecutor.ts:481-490
Hook: prepareIteration(ctx, budget) → IterationPlan
ConditionAction
budget.remaining / budget.maxIterations ≤ 0.1 Arm grace call (once). Inject system-reminder: "Budget nearly exhausted, summarize and produce final response."
Otherwise Return default plan: full tool set, no reminder.
The reminder is injected as a user message (not just appended to system prompt), ensuring the LLM sees it as a high-priority instruction.
Phase C: After LLM returns tool calls — agentTurnExecutor (tool execution segment)
Hook: interceptToolCall(ctx, call) → AsyncGenerator → InterceptResult
Intercepted ToolActionEffect
delegate_task Sets _delegationRound = true Parent budget NOT consumed this iteration (refund at loop end).
Tool still executes via normal handler (sub-agent dispatch).
transfer_to_agent Sets _delegationRound = true Same as delegate_task.
Any other tool Returns { handled: false } Tool passes through to normal execution handler.
Budget accounting: At loop end (agentTurnExecutor.ts:2431-2434), strategy.takeDelegationRound() is checked. If true, budget.refund(1) instead of budget.consume(1) — delegation rounds don't consume parent iteration budget.
Phase D: After each iteration, before continuing — agentTurnExecutor (budget gate)
Hook: shouldTerminate(ctx, budget) → boolean
ConditionReturnEffect
!budget.hasRemaining() && !budget.isGraceArmed() true Budget fully exhausted, no grace available. Main loop terminates.
Otherwise false Continue loop.
Grace mechanism: When budget drops to ≤10%, budget.armGraceCall() is called in prepareIteration. This allows 1 final iteration after budget exhaustion for the LLM to produce a summary. After the grace call is consumed, shouldTerminate returns true on next check.
Loop End: yield {type:'done'} — storeTurnObservations — return

5. Complete Lifecycle: One Turn

1
Strategy Instantiation
AgentLoopStrategyFactory.resolve(request, agentParadigm?) returns a new HermesReActStrategy instance. Budget = new IterationBudget(90).
2
preLoop Hook (once, before loop)
LLM assesses user intent → decides if exploration needed → dispatches parallel sub-agents → generates planTasks queue. Findings injected into messages context.
3
Enter while(iteration < 50) { ... }
Compression check → Tool assembly → prepareIteration() (budget low reminder)
4
LLM Call + Process Response
modelProvider.chat() → stream deltas → assemble content + toolCalls
5
interceptToolCall Hook
Check each tool call: if delegate_task/transfer_to_agent, mark _delegationRound = true (budget refund at loop end).
6
Tool Execution or Loop Termination
If no tool calls: classify incomplete turns, reflect phase, plan queue advance, or yield done.
If has tool calls: hardPermission → loop detection → parallel/serial execution.
7
Budget Accounting
If _delegationRound: budget.refund(1). Else: budget.consume(1). Checkpoint persist every 3 iterations.
8
shouldTerminate Hook
Check budget: if exhausted with no grace, terminate. Otherwise continue to next iteration or end normally.
