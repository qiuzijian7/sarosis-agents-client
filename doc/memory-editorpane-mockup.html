bug ☀️ WARM gulp 编译 ESM 扩展错误写入 out/package.json 导致 CJS/ESM 模式冲突 06-26 14:10 ▶
根因: gulpfile.extensions.ts 的 compileTask 在编译每个扩展后，无条件写入 out/package.json = {"type":"commonjs"}。但 ESM 扩展（package.json 有 "type": "module"）会被这个 CJS 声明覆盖，导致 Node.js 以 CJS 模式加载 ESM 代码。

修复: 在写入前检查扩展根 package.json 的 type 字段。如果 type === "module"（ESM 扩展），跳过写入。
