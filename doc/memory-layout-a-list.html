方案 A · 清单式（窄栏原生）

只做一件事：把「待你处理的条目」按行摆出来。没有说明段落、没有仪表盘、没有嵌套卡片——所有信息压到两行以内，300px 也不挤。

宽度主题状态
记忆库右栏
适合
  • 常驻在右栏 / 侧栏（280–380px），用户「扫一眼、点两下」就走。
  • 审核是主线、浏览是支线：点行 → 到中栏看证据、改、提升。
代价
  • 没有就地详情：多一次跳转（换来窄栏里不出现双栏挤压）。
  • 漏斗/健康这类「偶尔看」的东西只留一行数字，要点进维护页。
