VsSaros 知识库（Knowledge Base）使用报告

框架结构 · 特色功能 · 界面 Mockup 与使用说明 —— 基于代码实证整理（2026-09-20 最新状态）

IDE 内嵌 · 零外部服务 本地优先 / 离线可用 Agentic 构建（默认开启） BM25 + 向量 RRF 混合检索 目录摘要 L1 自动注入 Obsidian 风味笔记

1. 定位与总览

知识库（简称 KB）是 Agent Studio 里的「个人资料库」：把聊天消息、工作区文件、网页内容沉淀成结构化 Markdown 笔记，并建立双链图谱与语义索引，供用户浏览、检索，也供 Agent 在对话中调用。

维度说明
运行形态全部在渲染进程内完成（KbNativeKernel 内置内核），无需外部二进制、无需 IPC、无需主进程改动；离线可用
笔记格式Obsidian 风味 Markdown（frontmatter + [[双链]] + callout），与 Obsidian 生态兼容
构建方式Agentic 构建（默认开启）：由 knowledge-base-expert agent 构建（技能注入 + 工具），失败回退直连管线
Embedding可选。未配置时全文/图谱照常工作，语义通道自动降级（不报错）；embed 结果有磁盘缓存
核心入口侧边栏「知识库」视图 + 三处「导入知识库」按钮 + 三个 Agent 工具 + kb_overview 自动注入
与记忆系统（agentmemory）的分工：agentmemory 管「运行时记忆」（由网关子进程承载）；知识库管「用户沉淀的笔记资料」，落盘为可读可编辑的 Markdown 文件。

2.1 内核的三份索引（+即时一致性）

  • 全文索引 KbFullTextIndex：进程内倒排，BM25（文件名 +10、标签 +5），有持久化缓存与增量 reconcile
  • 图谱索引 KbLinkGraph：节点 = 文档 + 标签；边 = wikilink / blockref / tag；删除/重命名即时移除节点与边（removeDoc / removeDocsUnder / upsertDoc）
  • 向量索引 KbVectorIndex：语义切块 → 批量向量化 → cosine；持久化 .kbrag.json / .kvindex；provider tag 隔离 + embed 文本磁盘缓存（切换/切回 provider 不重复计算）

2.2 存储布局与产物

Vault 根默认为 ~/.vssaros/knowledge-base/<vault-id>/（可在设置面板改用任意文件夹）。

.kb-insights-cache.json社区摘要缓存（键 = 成员标题指纹）

2.3 导入与构建时序

  1. 阶段 1 落盘：解析 Vault 根 → schema 分类（失败降级 safeSchemaFallback）→ 写 库/raw/ → 追加 log.md → 打开知识库视图
  2. 阶段 2 构建（默认 agentic；直连为回退）：
    • agentic 路径（默认）：素材交给 AgentDriverService（agentId = knowledge-base-expert，chatOnly），技能注入 + 工具能力；产出 FILE 块文本
    • 直连路径（回退/显式关闭时）：Stage 1 结构化分析 → Stage 2 按 ---FILE: 块格式产出
    • 共用后半段：FILE 块落盘 → 注入来源双链 → 确定性补链（零 LLM 成本）→ 维护导航（index / overview / insights + 社区摘要 + 目录摘要）→ 去抽象化门控（派生类 ≥2 来源才 active）
构建缓存命中时直接返回已生成笔记（验证文件仍存在，两条构建路径共享缓存）；系统导航文件不作为构建源，避免「笔记→笔记」递归。

3. 特色功能

Agentic 构建（默认开启）

构建笔记由 knowledge-base-expert agent 完成：obsidian-markdown / defuddle 等技能强制注入 + 工具能力（可查已有笔记避免重复）；失败自动回退直连管线，缓存共享。

目录摘要 L1 自动注入

每轮用户消息自动携带 <kb_overview> 标签（各目录 .overview.md 摘要，TTL 60s + 1.5s 超时 + 1500 字符预算截断）；agent 可经工具渐进下钻。

混合检索（RRF）

BM25 全文 + 语义向量双通道按 1/(k+rank)（k=60）融合；结果带 [[引用]] 与命中目录摘要；无索引时静默降级并给引导。

双链图谱 + 即时一致性

LLM 产链 + enrichWikilinks 确定性补链；删除/重命名后 FTS、向量、图谱、提及四份索引即时剔除，不再残留幽灵文档。

社区检测与语义摘要

Louvain 社区 + 一次批量 LLM 生成主题名与摘要写入 insights.md；按成员指纹缓存，失败回退纯成员列表。

隐式双链建议

基于已存向量纯本地计算，排除已建链，推荐「语义相关但尚未链接」的笔记（kb_suggest_links）。

embed 文本缓存

向量计算结果按「tag + 文本指纹」落盘复用：重建大库、切换/切回 provider 不重复付费；容量 2 万条淘汰。

provider 一致性提示

向量索引 tag 与当前 embedding provider 不一致时，搜索语义区头部直接提示重建（无命中也提示）。

Schema 驱动分类

可配置类型体系指导分类与目录归类；模型未按前缀输出时按 frontmatter type 二次归类兜底。

去抽象化门控

派生类笔记需「≥2 个不同来源」确认才 active，配合别名归一抑制碎片噪音。

格式约定单源化

笔记格式规则集中在 obsidianNoteFormat.ts，构建提示词由它生成，与 obsidian-markdown 技能互为同步指针。

内核实例共享

视图与笔记编辑器共用同一内核实例（一次扫描、两份界面），编辑器可懒构建。

8. 已知边界与后续项

  • agentic 构建尚未真机验证：需重载 dev 后实际导入一篇验证（单测已覆盖正常/作废/空产出/缓存命中 6 例）
  • 文档理解层未接入：PDF / 图片 OCR 等深度解析不在本期范围；需要时可接外部解析（MinerU / RAGFlow）的输出再进导入管线，不建议自建
