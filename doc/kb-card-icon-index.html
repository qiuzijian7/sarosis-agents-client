一、开源项目怎么展示「知识库 / 空间」的图标 查证来源，非凭印象
项目范式具体做法与可引用依据
NotionEmoji / 自定义图 + 封面每个 Page 有独立 Page Icon（emoji 库或上传 PNG）与可选 Cover Image；图标显示在页面标题旁与侧栏条目上，是"视觉书签"。参考：Notion Help · Style & customise your page
AppFlowyEmoji + 自定义图片开源 Notion 替代品，ChangeIconPopover 支持 emoji 与 UploadImage（jpg/png/svg/webp），ViewIcon 统一渲染。参考：AppFlowy-Web · Icon System
Outline语义线性图标库 + 配色Collection 用 IconPicker 选一组语义图标（BookmarkedIcon / CollectionIcon / AcademicCapIcon / BeakerIcon / CodeIcon / GlobeIcon / LeafIcon / MathIcon / PaletteIcon…），单色线性、可换色。参考：outline/outline · IconPicker.tsx
BookStack书籍语义图标 + 封面以 Book/Shelf/Chapter 为信息架构，自带 book.svg / books.svg / bookshelf.svg / chapter.svg 图标集，书籍条目可带封面图。参考：BookStack · resources/icons
AFFiNE / Docmost 等首字母 Letter Avatar工作区/空间无自定义图标时，取名称首字（中文取首字、英文取缩写）配确定性渐变作头像，零配置、跨平台字形一致；常见于自托管 SaaS 的空间切换器。
Anytype / 思源 SiYuanEmoji + 彩色圆角底对象/笔记本图标 = 一个 emoji 落在低饱和圆角方块上，色块用于分组而非承载信息；与 Notion 同族，但不强制封面。
归纳出 4 类范式：① Emoji/自定义图（辨识度最高，要处理字形差异）；② 语义线性图标（最"文档工具"，克制、可主题化）； ③ 首字/缩写头像（零配置、稳定）；④ 封面 + 叠加图标徽章（保留现有渐变的过渡做法）。下面 5 套分别对应或组合它们。
二、5 套方案 点开看可交互 mockup；每页自带明暗切换、点击反馈与页内自检
方案 A

Emoji + 彩色圆角底

照 Notion / AppFlowy / Anytype。去掉纯色封面，换成 40px 低饱和圆角底 + 大 emoji；按库名关键词给默认 emoji，点图标可换。

辨识度 ★★★★★ · 改动 中 · 依赖系统 emoji 字形
方案 B

语义线性图标 + 主题色

照 Outline IconPicker / BookStack。内联 SVG 线性图标（coins/code/game/palette/cube/book），stroke 用 currentColor，按库语义分色。

克制 ★★★★★ · 改动 中 · 需维护图标映射表
方案 C

首字 Letter Avatar + 确定性渐变

照 AFFiNE / Docmost。中文取首字、英文取前两字母，复用现有 coverOf() 的 hash 色相 ⇒ 零配置、跨机型一致。

稳定 ★★★★★ · 改动 最小 · 语义弱于 emoji
方案 D

保留封面 + 叠加图标徽章

照 Notion 的 Cover + Page Icon。现有 78px 渐变不动，在左下压一枚 36px 徽章（emoji/首字），带描边与阴影。

改动 最小 ★★★★★ · 保留视觉惯性 · 仍是色块为主
