三个区域，一条打开链路

这份 HTML 验证交互方向。生产布局、插件注册和图片准入尚未修改。

  1. 会话列固定：退役中栏 TabStrip、旧主页入口和工作台聊天停靠；继续使用官方对话和工具卡。
  2. 目录自动同步：从工作台注册式 / 路由式 / 组件式入口汇成统一目录，订阅注册、卸载和启停。声明的子页签也拥有稳定 pageId。
  3. 右栏主页唯一：把现有 Dashboard 主页适配为原生 guide 的内容，释放 Better Sidebar 默认 guide 接管，避免两份主页竞争。
  4. 每次点击另开：Better Sidebar registerTab + createTab，多实例业务承载，不带第二个 conversation。开始页不 replace、不 close。
  5. 资源分流：@image:image.png 是拟支持的引用语法，不是已实现的协议。先按会话解析路径并经 Host 附件准入，交给官方图片预览器与工具卡。
  6. 按会话恢复：页签记录、工作区、未保存草稿不能依赖全局 active；没有会话时先展示主页，不暗中创建目录或会话。
