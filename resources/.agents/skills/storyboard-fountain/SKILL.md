# 分镜剧本生成（Fountain 格式）

生成符合导演台节点解析规范的分镜剧本文本。导演台通过 `fountainToBoards` 解析本格式，自动把每个场景转成一个分镜板（board）。

## 格式规范

### 场景标题（每个场景一段）
以 `INT.` / `EXT.` / `EST.` / `INT./EXT` 开头（或 `.` 开头），后接地点 + 时间：

```
INT. 客厅 - 白天
```

### 动作描述
场景标题后的普通行是画面动作描述，可多行。

### 角色对白
角色名单独一行（中文角色名用 `@` 前缀转义，避免被当成普通动作），下一行是对白文本：

```
@小明
我们出发吧！
```

### 注释（会被解析器忽略）
`[[注释]]` 或 `/* 注释 */` 会被忽略，可用于写分镜批注。

## 完整示例

```
INT. 咖啡馆 - 白天

小明推门进来，环顾四周。

@小明
有人在吗？

小美从柜台后抬头，微笑。

@小美
欢迎光临！要点什么？

EXT. 街道 - 傍晚

两人并肩走在夕阳下，影子拉得很长。
```

## 生成规则

1. 每个场景（INT/EXT 标题）→ 一个分镜板（board）
2. 动作行 → board 的「动作」字段
3. 对白 → board 的「对白」字段（格式 `角色: 对白`）
4. 角色 → board 的「角色」字段（去重汇总）
5. 输出纯文本，不要用 markdown 代码块包裹
