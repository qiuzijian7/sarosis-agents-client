# Summarize Skill

Use this skill when the user asks for a summary, overview, or condensed version of content.

## Guidelines

- Preserve key facts and main arguments
- Remove redundant or tangential information
- Maintain the original tone and intent
- Use clear, concise language
- Structure the summary with headings or bullet points for readability

## Summary Levels

- **Brief**: 1-2 sentences capturing the essence
- **Standard**: Key points in a short paragraph or bullet list
- **Detailed**: Comprehensive overview covering all major sections

Always ask or infer the desired summary level if not specified.
