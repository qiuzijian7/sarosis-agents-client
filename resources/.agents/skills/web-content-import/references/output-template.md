# 输出模板（web-content-import）

三种形态与宿主「导入链接」产物**逐字对齐**（`kbUrlScraper.composeArticleMarkdown` /
`composeVideoMarkdown` / `kbImportController.importUrl` 的拼接方式）—— 这样同一篇文章不论是你抓的
还是宿主导入的，预览、构建、飞书同步看到的结构都一样。

**要点**：素材**没有 YAML frontmatter**；元信息写成紧跟 H1 的一行 `> …`；图片一律**相对路径**。

---

## 一、文章（article：公众号 / 掘金 / CSDN / 博客 / 知乎文章 / 小红书图文）

```markdown
# <标题>

> 作者：<作者> · 来源：<站点名> · 发布：<YYYY-MM-DD>
> 平台：<平台中文名> · 原文：<原始 URL>

![封面](assets/<slug>/1-<原名>.<ext>)

**摘要**：<og:description 或你读到的一句话摘要>

<正文 —— 保留原文段落与标题层级；图片按出现位置用相对路径插入>

标签：<tag1> / <tag2>
```

规则：

- `作者 / 来源 / 发布` 缺失就整段省略对应项，**不要**写「未知作者」这类占位；
- 平台中文名取自平台表（小红书 / 抖音 / B站 / YouTube / 微信公众号 / 知乎 / 微博 …）；
- 封面拿不到就不写这一行；正文里**不要**重复插封面。
- 正文若是你从 `browser_snapshot` 读来的（SPA 页面），末尾加一行：
  `> ⚠ 正文取自浏览器渲染快照（非原始 HTML），可能缺少折叠内容 / 评论。`

## 二、视频（video：B站 / YouTube / 抖音 / 快手 / TikTok / 微博）

```markdown
# <标题>

> 作者：<UP 主 / 频道> · 平台：<平台中文名> · 时长：<mm:ss 或 h:mm:ss> · 发布：<YYYY-MM-DD>
> 原文：<原始 URL>
> 视频地址：<webpage_url>（直链：<url，没有就删掉这段>，抓取于 <YYYY-MM-DD>）

![封面](assets/<slug>/1-<原名>.<ext>)

> ⚠ 未抓取视频本体（几十 MB~GB，会拖慢索引与飞书同步）。要画面证据就抽帧（见 3.3），
> 并按 `[帧 mm:ss]` 标注 —— 只抽到封面时，整段画面结论一律标「未验证」。

**简介**：<description，截到 500 字符以内>

## 口播文本（字幕轨 / 本地 ASR 转写）

<口播纯文本 —— 来源二选一并在段首标注：`（字幕轨）` 或 `（本地 ASR 转写，可能有个别错字）`；
两者都没有时整段省略，并在结尾说明「无字幕轨且 ASR 不可用/失败，口播内容未获取」>

## 正文

<页面上的文字说明（如 B站简介下方的专栏 / 抖音文案），<80 字符就整段省略>
```

规则：

- **时长**用 `mm:ss`（≥1 小时才 `h:mm:ss`）；
- 口播文本的**唯一来源是音轨**（字幕轨或 `video_analyze` 内置 ASR）——**不要**拿抽帧读屏上文字冒充口播
  （屏上只有标题/UI 字，口播不在画面里）；都没有就如实写「未获取」，并给出去哪看（原文链接）；
- `## 正文` 段只在确有页面文字说明时写。

## 三、媒体（图片 / 视频地址 / 关键帧）—— 归档产物必须包含其一

### 3.1 文章里的关键图片

```markdown
<正文按原文顺序，图片就插在它出现的位置>

![图注](assets/<slug>/2-<原名>.png)
```

- 序号与文件名来自**实际落盘**的那个文件（`planImagePath` 的形态：`assets/<slug>/<序号>-<原名>.<ext>`）；
- 下载失败的那张**保留远程 URL**，并在文末「未获取」里写明哪张没下来、为什么（403 / 需要 Referer）；
- 头像 / 图标 / 表情 / 埋点图**不进正文**（判据：两维都小于尺寸阈值，或 URL 明显是 avatar/icon/logo/1x1）。

### 3.2 视频地址（视频帖**必写**这一行）

```markdown
> 视频地址：https://www.bilibili.com/video/BV1xx411c7mD（直链：https://…/x.m3u8，抓取于 2026-09-24）
```

- 直链**有时效**，所以必须标注"抓取于 <日期>"，并且页面地址与直链都要写（页面地址才是长期可用的那个）；
- 只有页面地址时：`> 视频地址：<页面 URL>`；解析失败时再加一句 `> ⚠ 未能解析直链：<原因>`。

### 3.3 视频关键帧（要看画面 / 要画面证据时）

```markdown
## 关键帧

![帧 00:00](assets/<slug>/frame-01.png)
![帧 03:12](assets/<slug>/frame-03.png)

> 帧由 `extract_video_frames` 抽出（共 6 张，间隔约 <n>s）；画面结论必须挂 `[帧 mm:ss]`。
```

- 帧图文件名与时间点**照抄工具返回**（`· <path>  @ mm:ss`），不要自己推算时间点；
- 抽帧失败时**删掉整段**，改成 `> 未抽帧：<原因>（可提供截图后继续）`。

## 四、字幕清洗（与宿主 `parseSubtitlesToText` 同口径）

从 `.vtt` / `.srt` 里逐行读，删掉：

1. `WEBVTT` 行、`NOTE …` / `Kind:` / `Language:` 行；
2. 所有含 `-->` 的时间轴行；
3. 纯数字行（SRT 序号）；
4. 行内 `<...>` 标签与 `&amp; &lt; &gt;` 实体；
5. **重复行**（自动字幕常把同一句逐词重复输出多遍 —— 相邻重复 + 全局重复都去掉）。

然后按行拼成纯文本，超过 **20000 字符**就截断（并在末尾标注「字幕已截断」）。

## 五、落盘前自检（逐条过一遍）

媒体（用户对归档产物的硬要求）：

- [ ] **关键图片**：文章/图文帖的正文里插了**内容图**（≤20 张），不是只有封面；图内文字读过的才敢写结论；
- [ ] **视频地址**：视频帖里有 `> 视频地址：…`（页面地址 + 直链，直链标了「抓取于 <日期>」）；
- [ ] **关键帧**：用户要看画面/要画面证据时，有「关键帧」段，内嵌 `assets/<slug>/frame-*.png`，且画面结论挂了 `[帧 mm:ss]`；
- [ ] **拿不到的写清了**：哪张图 403 / 哪个视频解析不出直链 / 哪个视频抽不了帧 —— 没有留空，也没有编；
- [ ] 头像 / 图标 / 表情 / 1×1 埋点图**没有**混进正文。

落盘与交付：

- [ ] 落点是 `<vault>/库/raw/<slug>.md`，**不是** `笔记/`（那是构建产物层）；
- [ ] 文件**没有** YAML frontmatter；首行是 `# 标题`；
- [ ] 元信息那几行用的是 `> …` 引用行；
- [ ] 每张图片都是**相对路径** `assets/<slug>/…`，且文件真的存在（下载失败的要保留远程 URL 并说明）；
- [ ] 同名文件已处理（追加 `-2` / `-3`，不要覆盖）；
- [ ] 没有任何 HTML / `<iframe>` / Dataview 之类预览与飞书都不渲染的语法；
- [ ] 结论里**分开**写了「已获取」与「未获取 / 需登录 / 无字幕」；
- [ ] 用户要归档时，已问过是否用 `kb_build` 构建成笔记（未获同意不要调 `mode:"build"`）。
