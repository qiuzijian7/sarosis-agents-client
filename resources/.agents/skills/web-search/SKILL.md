# Web Search Skill

Use this skill when the user asks for current information, facts, or anything that requires up-to-date knowledge from the internet.

## Guidelines

- Always verify facts from multiple sources when possible
- Cite sources when providing factual information
- Prefer authoritative sources (official docs, academic papers, reputable news)
- If search results are inconclusive, say so explicitly
- Use the most recent information available

## Search Strategy

1. Formulate clear search queries
2. Review top results for relevance and credibility
3. Extract key facts and data points
4. Synthesize findings into a coherent response
5. Include source citations
