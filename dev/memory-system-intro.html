Features

核心记忆机制特色

冻结快照注入

会话首轮一次性注入 <agentmemory-context>， 会话内不再刷新。确保前缀消息稳定，最大化 LLM KV Cache 命中率。

三因子保留评分

importance × recency × access 加权评估记忆价值， 低分记忆自动降级到短期区而非直接删除，保持全文可检索性。

Core/Archival 分层

Pinned 核心记忆不受 token budget 限制，优先级保留。 超预算时低分条目自动降级 (auto-page)， 保证关键信息始终可见。

BM25 + 向量混合搜索

前缀二分查找 O(log n) + 同义词加权扩展 + RRF 融合排序， 精确匹配 > 同义词 > 前缀三层递进。

多层去重保护

BloomFilter 预过滤 → SHA-256 精准去重 → toolCallId 维度去重。 防止流式重试、compaction 重放导致重复记忆写入。

注入幂等 + 上下文缓存

同一 session 仅注入一次 context；跨请求结果缓存（fingerprint + TTL）， 记忆状态不变时跳过全部组装管线。

Cache Optimization

13 项缓存命中率优化

对齐 agentmemory 源码，从算法级到应用级逐层优化 LLM 缓存命中率。

# 优化项 层级 描述 状态
P0 ContextBlock 抽象 + 固定组装管线 应用级 priority+recency 双重排序，固定块不受 budget 截断，保证跨轮次前缀一致 ✅
P1 BM25 惰性排序缓存 + lowerBound 算法级 倒排索引词条惰性缓存，写时失效；前缀匹配二分查找 O(log n) ✅
P3 跨请求 Context 结果缓存 应用级 fingerprint + 版本号 + 60s TTL，记忆未变时跳过组装管线 ✅
P4 Pre-compact 注入位置修复 应用级 注入消息放在固定 system 之后、摘要之前，保留前缀缓存 ✅
P6 SessionContextCache 复合键 应用级 agentId::sessionId 复合键，避免跨 session 串数据 ✅
P7 注入幂等去重 应用级 同一 session 仅注入一次 agentmemory-context ✅
P10 BM25 同义词加权扩展 算法级 精确=1.0, 同义词=0.7, 前缀=0.5×weight 三层递进 ✅
P11 读取时写回 accessCount 应用级 loadContext 选中后 fire-and-forget 写回 KV，提升热点记忆评分 ✅
P13 三因子加权评分 应用级 importance×0.5 + recency×0.3 + access×0.2 ✅
Getting Started

使用指南

1

AgentMemory 服务（自动启动）

# 生产模式：Sarosis 主进程自动拉起
# startAgentMemoryGateway → npx @agentmemory/agentmemory
# 监听 127.0.0.1:3111，无需手动干预

# 开发模式：手动启动独立服务
cd extensions/agentmemory-memory
npm install && npm run compile
node out/host.mjs   # HTTP 端点: GET/PUT /kv/...

自动启动：主进程通过 startAgentMemoryGateway 以子进程方式启动。
手动启动：开发调试时直接运行 host.mjs，管理 SQLite KV Store 和 BM25/Vector 索引。

2

运行单元测试

cd extensions/agentmemory-memory
npx tsc -p ./tsconfig.json
node out/__tests__/runAllTests.js

# 输出: 181 passed, 0 failed

181 个单元测试覆盖全部核心模块：BM25 搜索、向量索引、去重、RRF 融合、4-Tier 类型映射、技能提取、Lesson 衰减、Project Profile、Slots 编辑、Routines 编排等。

3

通过 AgentOS 使用记忆

// Agent 对话中自动记忆
// 1. 每轮 fire-and-forget 写 working memory
// 2. 每 3 轮触发 L1 自动提取 Episodic
// 3. LLM 工具: memory_remember/search/delete/list
// 4. 会话开始注入 <agentmemory-context>

完全自动化，无需手动配置。Agent 可直接调用 memory_remember 工具写入自定义记忆。

4

配置 Token 预算与策略

// Agent 请求参数
{
  memoryStrategy: "full",    // summary | full
  memoryScope: "agent",      // agent | global
  memoryMaxEntries: 50       // 可选
}

// memoryProvider 内部常量
TOKEN_BUDGET = 4000          // context 组装预算
RETENTION_FLOOR = 0.01       // 保留评分阈值

summary 策略仅注入 Episodic 记忆，full 策略同时注入 Working 最近上下文。

Module Guide

9 大模块详细使用指南

每个模块的原理、API 签名、典型用法

🧠

1. 记忆 (Memory)

4-Tier 记忆层级

原理

四级分层记忆模型，对齐 agentmemory：Working → Episodic → Semantic → Procedural。

  • • Working: 每轮 fire-and-forget
  • • Episodic: L1 自动提取（每 3 轮）
  • • Semantic: LLM 跨会话固化
  • • Procedural: XML 步骤提取

用法

await memProvider.writeMemory(agentId, {
  type: 'working',
  content: 'user message',
  metadata: { source: 'user_input' }
});

const ctx = await memProvider.loadContext(
  agentId, sessionId, query,
  { scope: 'agent' }
);
📌

2. 槽位 (Slots)

可编辑固定记忆

原理

8 个固定槽位（persona、user_preferences、project_context 等），可设置 pinned 标志优先注入。

  • • sizeLimit: 500~2000 字符
  • • pinned: 受 budget 保护
  • • readonly: 不可修改

用法

const slots = memProvider._slots;
slots.set(agentId, 'persona',
  'You are a coding assistant');
slots.append(agentId, 'user_preferences',
  'use tabs over spaces');
slots.pin(agentId, 'project_context', true);
const ctx = slots.buildContext(agentId);
📖

3. 教训 (Lessons)

经验沉淀与衰减

原理

从对话中自动提取经验（"should/must/always"模式 + 错误模式），支持强化、衰减、软删除。

  • • DECAY_DAYS=60, FACTOR=0.95
  • • MIN_CONFIDENCE=0.2
  • • 24h 提取节流

用法

const le = memProvider._lessons;
const lessons = le.extract(agentId, entries);
le.reinforce(agentId, lessonId);
le.delete(agentId, lessonId);
const top = le.getTopLessons(agentId, 5);
🔄

4. 固化 (Consolidation)

4-Tier 跨层提取

原理

LLM 驱动的 4-Tier 提取管道，XML 解析 (<facts>, <procedures>) + 规则回退。

  • • Episodic: 3 轮后触发
  • • Semantic: 5 条 episodic 后
  • • Procedural: 3 条 semantic 后

用法

const pipe = new ConsolidationPipeline();
pipe.setSummarizer(async (prompt) => {
  return '...';
});
await pipe.consolidateEpisodic(agentId, entries);
await pipe.consolidateSemantic(agentId);
await pipe.consolidateProcedural(agentId);
📋

5. 审计 (Audit)

全量操作日志

原理

记录所有记忆操作（write/search/delete/decay/sweep/reinforce/consolidate 等）用于诊断和合规。

  • • 16 种 AuditOperation
  • • cache_hit (P3 新增)
  • • getSummary() 统计

用法

const audit = memProvider._audit;
audit.record('write', agentId, [entry.id], {
  contentLength: content.length
});
const summary = audit.getSummary();
// { write: 42, cache_hit: 8, ... }
🪝

6. 钩子 (Hooks)

生命周期事件订阅

原理

事件驱动钩子系统，支持 session_start、session_end、prompt_submit、subtask、tool_call 等生命周期事件。

  • • trigger(): 同步触发
  • • register(): 注册处理器
  • • triggerAndCollect(): 收集结果

用法

const hooks = memProvider._hooks;
hooks.register('session_end',
  async (ctx) => {
    // 清理资源
});
await hooks.triggerAndCollect(
  'prompt_submit', { agentId, userMessage }
);
✅

7. 提交 (Commits)

记忆与代码关联

原理

将记忆条目与 Git 提交关联，记录每条记忆的"作者"和"代码变更上下文"。

  • • link(): 关联提交
  • • getHistory(): 查询历史
  • • 跨 session 跟踪

用法

commits.link(agentId, memoryId, {
  commitHash: 'abc123',
  filePath: 'src/memoryProvider.ts',
  diffSummary: 'Added P12 auto-page'
});
const history = commits.getHistory(memoryId);
📊

8. 报告 (Report)

记忆健康度报告

原理

生成 Agent 记忆系统健康度报告，包括记忆分布、衰减情况、Top 概念、Top 教训、最近活动等。

  • • byType 分布
  • • avgStrength
  • • topConcepts/Lessons
  • • recentActivity

用法

const report = memProvider.generateReport(
  agentId,
  { includeRaw: false, maxEntries: 100 }
);
// { totalMemories: 142,
//   byType: { working: 30, episodic: 80 },
//   topConcepts: [...], ... }
⚡

9. 技能 (Skills)

可复用知识沉淀

原理

从重复工作流中提取可复用技能，生成 SKILL.md 文件保存到 ~/.saros/skills/<slug>/。

  • • 指纹去重（相同 trigger → 强化）
  • • 自动生成 SKILL.md
  • • frontmatter + markdown body

用法

const skill = se.extract({
  sessionId, agentId,
  observations: [...],
  trigger: 'config-update'
});
se.reinforce(skill.id);
se.markWritten(skill.id);
const md = generateSkillMd(skill);
