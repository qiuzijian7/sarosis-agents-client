设计要点
🎨 优先级色条
左侧 3px 色条：
■ 高优先 red
■ 中优先 yellow
■ 低优先 gray
🔄 状态差异
不同状态显示不同操作按钮：
待执行 → 聊天/执行/归档/删除
执行中 → 聊天/停止
已完成 → 查看/归档/删除
阻塞 → 解除阻塞/删除
已取消 → 恢复/删除
👆 交互细节
Hover: 上浮 + 阴影 + 操作按钮出现
Active: 缩放到 0.98
Drag: 拖拽排序
执行中: 蓝色呼吸灯动画
阻塞: 红色背景
📐 尺寸变体
标准: 标题 + 描述 + 标签 + 脚注
紧凑: 标题 + 脚注 (隐藏描述/标签)
最大行数: 标题2行, 描述1行
展开: 点击展开完整描述
