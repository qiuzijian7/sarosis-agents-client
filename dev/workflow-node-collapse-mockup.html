实现要点：
  • 按钮位置：.node-header 内部，.node-status 左侧（如截图红框所示位置）
  • 状态存储：每条 node 记录新增 userCollapsed: boolean 字段，初始 false
  • "不自动展开"机制：当 userCollapsed === true 时，跳过所有自动展开逻辑（包括 delta 推送时的滚动/展开）。只有用户再次点击按钮才会设为 false 并展开
  • 摘要行：收缩后显示 <div class="node-summary">，包含工具调用计数和输出字数统计
  • 样式：22x22px 小按钮，hover 高亮，使用 chevron 图标（▼ 展开态 / ▶ 收缩态），无需外部图标库
