方案 A — 顶部右侧悬浮工具栏 推荐

Hover 时卡片右上角弹出图标按钮组，scale(0.85)→scale(1) 放大动画。 按钮 hover 时 scale(1.15) 再次放大，带 tooltip 提示。 不改变卡片高度，仅悬浮覆盖在内容上方。

设计对比

  • 方案 A — 顶部右侧悬浮工具栏：不改变卡片尺寸，5 个图标按钮，hover 放大 scale(1.15)，带 tooltip。推荐首选。
  • 方案 B — 底部展开式：卡片高度变化，按钮带文字标签，操作语义更清晰。
  • 方案 C — 圆形 FAB：右侧悬浮圆形按钮，视觉突出，适合 3-4 个主要操作。
  • 方案 D — 右侧侧滑面板：窄面板 width 动画，按钮 stagger 错开入场。
  • 方案 E — 整体放大 + 顶部栏：卡片 scale(1.03) 放大，顶部展开文字按钮行，视觉冲击最强。

交互细节

  • 卡片 hover：translateY(-2px) 上浮 + border-color 变蓝 + 阴影加深
  • 左侧优先级色条 hover：width: 3px→4px 加宽
  • 按钮入场：opacity 0→1 + scale(0.85)→1，180ms 缓动
  • 按钮 hover：scale(1.15) 再次放大，背景色高亮
  • Danger 按钮 hover：红色背景 + 红色文字
  • Tooltip：按钮下方/左侧弹出，10px 字号，带边框和阴影
  • 动画曲线：cubic-bezier(0.4, 0, 0.2, 1) Material Design 标准缓动
