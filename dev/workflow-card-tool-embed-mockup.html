  • 数据结构：subAgent 需要新增 streamParts 数组，按时间顺序存储文本片段和工具调用（{ type: 'text', content } | { type: 'tool', toolCall }）

  • 兼容性：无 streamParts 的旧数据回退到当前渲染方式（node-output + tool-list）
  • 展开/折叠：工具卡详情默认折叠，点击 header 展开/收起
