📋 AutoGit

版本管理设计方案

每次 Ctrl+S 自动生成一个 Git commit，用户无需手动操作。

实现原理

  • 存储：Vault 目录下 .git/ 仓库
  • 引擎：isomorphic-git（纯 JS，无 native 依赖）
  • 触发：2s auto-save 完成后 → git.add() + git.commit()
  • 消息：auto: 2026-07-11 19:24:05

API 设计

class KbVersionService {
  init(vaultRoot: URI): Promise<void>
  autoCommit(vaultRoot, docPath): Promise<{sha, msg}>
  fileHistory(vaultRoot, docPath): Promise<CommitMeta[]>
  fileDiff(vaultRoot, docPath, sha): Promise<UnifiedDiff>
  restoreFile(vaultRoot, docPath, sha): Promise<void>
  cleanup(vaultRoot, retentionDays): Promise<number>
}

右侧面板

点击右侧时间线 → 展开 diff → 点击 Restore 恢复到任意版本。
