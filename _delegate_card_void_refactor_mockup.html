Delegate 卡片 Void 风格重构（统一滚动列表方案）
• 标题行：chevron + 🤖 + 标题「委派任务 / 子代理名 / 任务名」+ 右侧 状态 pill + 时长（并行 fan-out 时显示「并行 ×N」）。
• 展开体 = 单个可滚动列表（.delegate-scroll）：三段顺排于同一滚动容器内 ——
  ① 任务指令：args.task 的 markdown 渲染；
  ② 执行列表：所有子代理工具调用的扁平步骤时间线（✓ / ● / ✗ + 名称 + 摘要 + 耗时）；
  ③ 执行结构：子代理分解树（角色 + 任务 + 状态，逐子代理展开其工具步骤叶子）。
• 与现存「delegate 伞 + 独立 subagent 卡片」方案不同：本方案将指令/列表/结构压平进同一滚动列表，符合本次需求。
