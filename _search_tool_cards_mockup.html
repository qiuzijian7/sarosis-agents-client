📋 格式总结

工具 输出格式 结构 卡片类型
search_graph TOON pipe 分隔表格 + 头行 表格卡片（Symbol/Type/File/Score）
trace_path TOON pipe 分隔 hop 表 路径链卡片（H0→H1→H2...）
search_code JSON {results:[{filePath,lineNo,text,symbol}]} 代码块卡片（file:line + context）
query_graph JSON {rows:[{f.name,relation,g.name}]} 表格卡片（动态列）
get_architecture JSON {totalNodes,totalEdges,languages,communities} 统计网格 + 社区卡片
index_repository JSON {filesScanned,nodesExtracted,edgesExtracted} 统计网格卡片
search_files TEXT file:line 行列表 文件列表卡片（可点击）
get_code_snippet TEXT 带行号的源码文本 代码块卡片（语法高亮）
grep JSON {results:[{filePath,lineNo,text}]} 同 search_code
index_status JSON {nodeCount,edgeCount,projects[]} 统计卡片
