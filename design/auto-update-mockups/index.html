B 空闲自动重启 0 次 空闲且无脏数据后 中，可取消 希望真正全自动，同时保留安全边界 中：空闲检测 + 会话/脏数据判断
C 托管发布 0 次 维护窗口 由策略控制 企业批量设备、system setup 大：管理员服务与灰度回滚

与现有代码的映射

检查更新update.mode 从 manual 改为 default / start；自动模式下直接调用 startBackgroundDownload()。
去掉弹窗自动模式跳过 promptForUpdate() 与 promptForRestart()；手动入口仍保留。
安装器doApplyUpdate() 已使用 /verysilent；doQuitAndInstall() 可统一为 /verysilent。
重启策略新增 update.autoRestart：onQuit / idle / managed。
企业方案由外部服务或计划任务运行系统级安装包，应用内只读取策略状态。

三套方案共用的安全底座

静默不等于无保护。以下能力不能随弹窗一起删掉：

PRE-INSTALL HOOKspawn 前释放 dsh Host，避免 koffi.node 错误代码 5。
PREPARE TO INSTALL安装包内再次清理生产运行时进程，覆盖手动安装。
INTEGRITYSHA-256、断点续传、取消标记、进度文件与日志。
FALLBACK保留 restartreplace；失败进入下次重试，不弹死胡同。
