# KB 文章管理测试计划

> 参考 obsidian-skills 的文章管理体系（frontmatter 元数据、标签层级、wikilinks 双链、MOC 知识地图），
> 测试本项目知识库从多源导入后的文章生成、归类、组织功能。

## 一、obsidian-skills 关键设计模式（参考基准）

| 模式 | obsidian-skills 实现 | 本项目对应 |
|------|---------------------|-----------|
| Frontmatter 元数据 | YAML 首部（title/tags/aliases/date/status） | URL 导入有 meta tags，文件导入无 |
| 标签系统 | `#tag#` + 嵌套 `#parent/child#` | `#tag#` 扁平标签，无层级 |
| Wikilinks | `[[Note]]` / `[[Note\|alias]]` / `[[Note#heading]]` | 已支持，有反链图谱 |
| 嵌入引用 | `![[Note]]` 跨笔记 transclusion | 已支持（embed 组件） |
| MOC（知识地图） | 手动创建索引笔记链接相关文章 | 无自动 MOC 生成 |
| 文章结构 | frontmatter + 标题层级 + 标签 + 双链 | 无标准化结构 |
| URL 提取 | defuddle 技能（干净 Markdown 提取） | WebContentExtractor + 12 平台识别 |

## 五、obsidian-skills 设计模式应用建议

基于分析，建议本项目引入以下 obsidian-skills 模式：

1. **Frontmatter 标准化**：所有导入内容自动添加 `title/source/platform/date/tags` frontmatter
2. **嵌套标签**：支持 `#parent/child#` 层级标签（当前仅扁平 `#tag#`）
3. **MOC 自动生成**：基于标签聚类 + 双链关系自动生成知识地图文件
4. **AI 自动打标签**：导入时 LLM 分析内容 → 建议 `#标签#` → 写入文件
5. **AI 文章合成**：基于 RAG 检索多源知识 → 生成结构化文章（含 frontmatter + 双链引用）
6. **Defuddle 式 URL 提取**：增强 URL 导入的正文提取质量（当前 WebContentExtractor 可能遗漏内容）
