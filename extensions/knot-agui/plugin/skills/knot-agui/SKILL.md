# Knot AG-UI

Interact with remote intelligent agents via the Knot AG-UI protocol.

## What You Can Do

- Chat with enterprise AI agents hosted on the Knot platform
- Watch agents reason through problems step by step (thinking mode)
- See tool calls executed in real time as the agent works
- Switch between multiple agents for different tasks

## Getting Started

1. Open Settings → Knot and enter your API Token
2. Choose an agent from the model selector
3. Start chatting!

## Requirements

- A valid Knot API Token (generate one at knot.woa.com/console/tokens)
- Network access to the Knot AG-UI endpoint
