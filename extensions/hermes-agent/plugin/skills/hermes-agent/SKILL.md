# Hermes Agent

Use the Hermes Agent framework for autonomous AI tasks with tool-calling capabilities.

## What You Can Do

- Connect to 28+ model providers (Anthropic, OpenRouter, Gemini, DeepSeek, etc.)
- Execute 70+ built-in tools (web search, terminal, file ops, browser, vision, etc.)
- Maintain persistent memory across sessions
- Delegate complex tasks to sub-agents
- Stream responses with real-time thinking and tool call display

## Getting Started

1. Open Settings → Hermes Agent and configure your Python path and API key
2. Select a model provider (e.g. `anthropic`, `openrouter`)
3. Choose a model (e.g. `claude-sonnet-4-20250514`, `gpt-4o`)
4. Start chatting — the agent will reason and use tools autonomously!

## Requirements

- Python 3.10+ with hermes-agent dependencies installed
- At least one API key for a model provider
- Network access for API calls and web tools

## Upgrading

- Use "Hermes: Upgrade Repository" to pull latest hermes-agent code
- Use "Hermes: Install Dependencies" after upgrading
