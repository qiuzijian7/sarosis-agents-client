大规模标签 · 显示策略

当标签数量膨胀（数十~数百），核心思路是不一次铺开全部：

① 标签内搜索：顶部输入框按名称实时筛选标签组，先缩小范围再浏览。
② 数量阈值：仅显示 ≥N 过滤掉仅 1 篇的"噪声标签"，聚焦高价值分类。
③ 排序：热度↓（常用在前）/ 字母↑ / 层级，适应不同查找习惯。
④ Top-N + 显示更多：列表默认只渲染前 N 个热门标签组，其余折叠在"显示其余 X 个 ▾"后惰性展开（模拟虚拟滚动）。
⑤ 三视图切换：
· 列表：扁平分组（上述①②③④）
· 层级：用 / 表达父子（项目A/前端），树状收起
· 云：字号∝文档数，俯瞰全局热度
⑥ 置顶常用：★ 行固定高频标签，跨筛选常驻。

纯前端 demo，未改项目代码。真实实现可接 _index.searchByTag 聚合 + 虚拟滚动（如 VS Code 原生 tree 的 compress 模式）。
