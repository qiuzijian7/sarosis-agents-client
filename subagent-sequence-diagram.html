SubAgent 执行时序图

sequenceDiagram autonumber participant User as User participant USD as UnifiedSubAgentDispatch participant EF as ExecuteFn(AgentOS) participant Budget as IterationBudget User->>USD: createSubAgent(parentAgentId, task, options) activate USD USD->>USD: 创建 SubAgentInstance USD-->>User: 返回 subAgentId deactivate USD User->>USD: executeSubAgent(subAgentId, executeFn) activate USD USD->>USD: 检查状态(pending) USD->>USD: _buildMessages(subAgent) USD->>USD: _buildSystemPrompt(subAgent) USD->>EF: executeFn(request, budget) activate EF EF->>EF: agentOSService.executeAgentTurn() loop 流式响应 EF-->>USD: IChatStreamDelta(text/tool_end/done/error) USD->>USD: 累积 output alt delta.type == tool_end USD->>Budget: consume(1) Budget-->>USD: hasRemaining() alt 预算耗尽 USD->>USD: break 停止执行 end end end EF-->>USD: 执行完成或超时 deactivate EF alt 执行成功 USD->>USD: status=done, result={success:true, output} else 执行失败 USD->>USD: status=error, result={success:false, error} end USD-->>User: 返回 SubAgentResult deactivate USD Note over User,USD: 并行执行多个 SubAgent User->>USD: executeMultipleSubAgents(subAgentIds, executeFn) activate USD USD->>USD: 分批执行(尊重maxConcurrent) loop 每批最多 maxConcurrent 个 par subAgent1 执行 USD->>EF: executeSubAgent(id1, executeFn) EF-->>USD: SubAgentResult and subAgent2 执行 USD->>EF: executeSubAgent(id2, executeFn) EF-->>USD: SubAgentResult and subAgentN 执行 USD->>EF: executeSubAgent(idN, executeFn) EF-->>USD: SubAgentResult end end USD-->>User: 返回 Map(subAgentId, SubAgentResult) deactivate USD
