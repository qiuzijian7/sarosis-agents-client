配置 Agent 的行为规则和约束
🔒
安全规则
禁止执行可能删除文件的命令（rm -rf, del /s 等），禁止修改 .git 目录
📝
代码审查规则
修改代码前必须先阅读目标文件，修改后必须检查 lint 错误
🎯
任务完成规则
完成任务后必须验证编译通过，并总结所做的改动
🌍
语言规则
始终使用简体中文回复
